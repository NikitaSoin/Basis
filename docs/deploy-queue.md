прочитай его целиком. Правило и причина — в `CLAUDE.md`, раздел «Параллельные
сессии» (⚙️ Технические правила).

## Статус: ЗАНЯТО

- Сессия: геополитика (карта/очаги/барометр)

- Пушит: чекпойнт в журнал по карте (фокус за фильтром + свежесть ударов).
  Код этой работы УЖЕ на бою — доехал вместе с деплоем макро-сессии.
- Ждёт: только docs, фронт-бандл менять не должен — освобожу сразу после push
