# Программный доступ к Яндекс.Вебмастеру

Чтобы смотреть статус индексации без ручных выгрузок CSV, нужен OAuth-токен. Выдаёт его
ваш аккаунт Яндекса — сделать это может только владелец, у меня доступа к нему нет.

## Что это даёт

Наш собственный лог видит только ВИЗИТЫ робота. Решение — брать страницу в поиск или
нет — принимает Яндекс, и знает об этом только Вебмастер. Разница принципиальная: 558
обойденных страниц могут дать и 500 в поиске, и 50.

С токеном я смогу сам смотреть: сколько страниц в поиске и как менялось, сколько скачано
роботом по дням, по каким запросам показывают и на каких позициях — и отправлять адреса
на переобход, не гоняя вам файлы.

## Как получить токен (5 минут)

**1. Создать приложение.** Открыть <https://oauth.yandex.ru/client/new/>

- Название — любое, например «Basis — статистика».
- Платформа — «Веб-сервисы», Redirect URI указать
  `https://oauth.yandex.ru/verification_code`.
- В разделе «Доступ к данным» найти **Яндекс.Вебмастер** и отметить:
  - «Получение информации о сайтах пользователя» (`webmaster:hostinfo`)
  - «Добавление сайтов и подтверждение прав» (`webmaster:verify`) — нужно для переобхода.

Сохранить. Появится **ClientID**.

**2. Получить токен.** Открыть в браузере, подставив свой ClientID:

```
https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
```

Подтвердить доступ. Яндекс перебросит на страницу, где в адресной строке будет
`access_token=...` — это и есть токен. Скопировать всё до символа `&`.

**3. Передать мне.** Токен — как пароль: даёт доступ к данным сайта в Вебмастере.
Положить его нужно в `backend/.env` (файл в `.gitignore`, в репозиторий не попадает):

```
YANDEX_WEBMASTER_TOKEN=здесь_токен
```

Можно прислать мне в чат — я впишу сам. Но учтите: переписка сохраняется, поэтому если
токен когда-нибудь перестанет быть нужен, его стоит отозвать на
<https://passport.yandex.ru/profile/access>.

## Как пользоваться

```bash
cd backend
python3 scripts/webmaster.py summary      # страниц в поиске, ИКС, динамика
python3 scripts/webmaster.py crawl        # сколько страниц робот скачал по дням
python3 scripts/webmaster.py queries      # запросы, показы, клики, позиции
python3 scripts/webmaster.py recrawl файл # отправить адреса на переобход
```

🔴 Скрипт только читает. Единственная операция, что-то меняющая, — переобход, и она
требует явно указать файл со списком. Настройки сайта отсюда не трогаются.

## Срок жизни токена

Токен действует год, потом его нужно выпустить заново тем же способом. Если запросы
начнут отвечать 401 или 403 — почти всегда это он, а не поломка.
