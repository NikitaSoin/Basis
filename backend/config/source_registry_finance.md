# Реестр источников — сектор ФИНАНСЫ

> **Назначение.** Список внешних источников, по которым платформа может автоматически
> обновлять две вкладки карточки компании: **«Рынки»** (`market.json`) и
> **«Корпоративное управление»** (`governance.json`).
> Формат задан файлом `source_registry_metallurgy.md` — здесь он повторён.
>
> **Составлен:** 2026-08-07. **Компаний в секторе:** 28 тикеров
> (`SELECT ticker,name FROM companies WHERE sector='Финансы'` — фактический состав БД).
> **Как проверялась доступность:** `curl -L` с браузерным User-Agent с dev-машины (не РФ IP).
> Фиксировались HTTP-код, конечный URL после редиректов, размер тела и наличие ЦЕЛЕВОГО
> контента в HTML (заголовок раздела, ссылки на .xlsx). Различались три исхода:
> `000` (нет TLS/ответа) / `200 с данными` / `200-заглушка` (JS-каркас без контента).
> Где написано «не проверял» — стоит `unknown`, и URL взят из уже процитированных
> в `companies/*/market.json|governance.json` (то есть однажды работал).

### 🔴 Четыре системных вывода по доступу (действуют на весь реестр)

1. **🟢 ГЛАВНАЯ ХОРОШАЯ НОВОСТЬ: `cbr.ru` полностью ОТКРЫТ с не-РФ IP.**
   Проверено 2026-08-07: 20+ разделов отдают **200 и реальный HTML** (заголовки разделов
   сверены, ссылки на .xlsx присутствуют), прямые скачивания `.xlsx` работают
   (`Content-Type: application/vnd.openxmlformats-...`). Это принципиально отличает
   сектор ФИНАНСЫ от металлургии/нефтегаза, где главные источники (ФАС, Росстат, ФТС)
   упираются в гео-блок. **Регулятор сектора — самый доступный источник, какой у нас есть.**
   ⚠️ Единичные таймауты бывают (`/analytics/finstab/orfr/` при первом заходе дал `000`,
   при повторе — `200`). Парсер обязан ретраить, а не помечать «недоступно» с первого раза.

2. **🔴 ЗЕРКАЛЬНАЯ ПЛОХАЯ НОВОСТЬ: сайты САМИХ банков геоблокируют не-РФ IP жёстче, чем gov.ru.**
   `000` (TLS не поднимается) у: `sberbank.com`, `sberbank.ru`, `vtb.ru`, `bspb.ru`,
   `ir.mkb.ru`, `ir.tbank.ru`, `uralsib.ru`, `spbexchange.ru`, `asv.org.ru`, `дом.рф` (IDN).
   `401`/`403` (antibot) у `sovcombank.ru`, `sistema.ru`.
   Это **не «сайт лежит»** — с боевого Timeweb (РФ IP) они, скорее всего, `open`, но это
   надо подтвердить ИМЕННО ОТТУДА. Практический вывод: **покомпанийный слой сектора
   нельзя строить и тестировать с дев-машины** — только через боевой пробник
   `/api/debug/probe-source?url=...`.
   🔵 Обходной путь для `дом.рф`: домен IDN, curl не резолвит кириллицу, но **punycode
   работает**: `https://xn--d1aqf.xn--p1ai/analytics/` → 200, 126 КБ, реальный контент.

3. **e-disclosure.ru — подтверждён `antibot`.** `company.aspx?id=11328` (Мосбиржа) отдаёт
   **200 и 372 182 байта** — ровно тот же размер JS-заглушки, что зафиксирован в реестре
   металлургии. Старый рецепт `curl -A` не работает. Для финансов это менее критично,
   чем для металлургии: у ЦБ есть СВОЙ реестр собственников (см. A1.12).

4. **Отраслевых RSS у сектора практически нет.** Единственный рабочий — `frankmedia.ru/feed`
   (уже подключён). У ЦБ RSS по нужным разделам не найдено, у Мосбиржи — тоже.
   Всё остальное — HTML-парсинг и скачивание .xlsx. Зато у ЦБ есть **стабильные пути
   к файлам** (`/vfs/statistics/pdko/int_rat/*.xlsx`), которые не меняются от выпуска
   к выпуску — это лучше RSS.

# В. ДЫРЫ — чего не хватает и что с этим делать

### В1. Инфраструктура и доступ

1. 🔴 **Нужна таблица идентификаторов «тикер → ИНН → ОГРН → рег.номер КО у ЦБ».**
   Это ЕДИНСТВЕННОЕ, что отделяет нас от автоматического сбора форм 101/102/135 и структуры
   собственности по всем 28 тикерам. У ЦБ ключ — рег.номер (`coinfo/?id=`) и ОГРН
   (`finorg/foinfo/?ogrn=`), у зеркал раскрытия — ИНН, у e-disclosure — свой ID.
   *Что делать:* завести справочник в `backend/config/` (по образцу `share_classes.json`),
   заполнить один раз руками/полуавтоматом из `FullCoList` (A1.11) и карточек ЦБ.
   Без него весь ЦБ-контур не запускается. **Это шаг №0.**
2. **Сайты российских банков геоблокируют дев-машину сильнее, чем gov.ru.** 8 из 28 эмитентов
   недоступны с ноутбука (`000`/`401`/`403`), при этом их URL живые и цитируются в карточках.
   *Что делать:* не делать ложных выводов «сайт мёртв»; поднять пробник
   `/api/debug/probe-source?url=...` на бою и один раз прогнать по всем 28 доменам, результат
   записать в этот файл. То же — для АСВ (A4.8), НРД/НФА (A4.10).
3. **e-disclosure под JS-челленджем** (подтверждено: 372 КБ заглушки). Для финансов это
   **менее болезненно**, чем для металлургии: реестр ЦБ (A1.12) закрывает структуру
   собственности по всем поднадзорным. Через e-disclosure остаются только AFKS, BTBR и часть
   истории по холдингам. *Что делать:* не строить пайплайн на e-disclosure как на основном канале.
4. **Собственных RSS у сектора нет** (кроме уже подключённого frankmedia). Зато у ЦБ есть
   **стабильные пути к .xlsx** (`/vfs/statistics/pdko/int_rat/*.xlsx`) — крон по ним надёжнее RSS.
   А вот `Collection/File/<id>/obs_NNN.xlsx` (A1.3) и файл MOEX (A3.1) — с меняющимися ID,
   их надо парсить со страницы-хаба.

### В2. Данные

5. **Процентная маржа сейчас ничем не питается.** Ни NIM сектора, ни спред ставок в платформе
   нет — есть только ключевая ставка. Это центральная метрика вкладки «Рынки» для 12 банков
   из 28. *Что делать:* A1.2 (ставки, `open`, стабильные URL) — **первый по приоритету коннектор
   всего сектора**, дешевле и полезнее всего остального.
6. **Доли рынка по банкам не считаются автоматически.** Числитель (форма 101 по банку) и
   знаменатель (A1.3) есть оба и оба `open` — но их надо СВЕСТИ. Готовые доли есть у Frank RG
   (A5.2), но глубина платная. *Что делать:* считать самим из ЦБ-форм — это честный `факт`
   с методикой, а не `оценка` из статьи Коммерсанта (как сейчас в металлургии).
7. **Лизинга у ЦБ нет вообще.** Все правдоподобные пути (`/develop/leasing/`, `/statistics/leasing/`,
   `/analytics/nfo/leasing/`) — 404. Рынок лизинга измеряет только **Эксперт РА** (A4.1).
   Для LEAS и SFI это монопольная зависимость от одного источника. *Что делать:* принять,
   помечать источник явно; при недоступности RAEX честно ставить `data_flag`.
8. **АСВ недоступно → отчисления в фонд страхования вкладов и структура вкладов по размеру
   не покрыты.** Ставка отчислений — прямой расход всех розничных банков.
   *Что делать:* проверить с боевого; если `open` — подключить, если нет — брать из
   пресс-релизов ЦБ и отмечать `оценка`.
9. **AFKS не принадлежит этому сектору по существу.** АФК «Система» — инвестхолдинг; её «Рынки» —
   это телеком + e-commerce + лес + девелопмент + фарма, ни один источник финансового реестра
   их не описывает (ровно та же проблема, что с SGZH в металлургии). *Что делать:* либо
   разметить как «холдинг» с наследованием источников портфельных секторов, либо гарантированно
   писать ей в «Рынки» чужие цифры. Для SFIN проблема мягче (два рынка: лизинг + страхование,
   оба покрыты).
10. **BTBR не покрыт ни одним отраслевым источником.** В2В-РТС — электронная торговая площадка
    (закупки), а не финансовая организация: ЦБ её не надзирает, `finorg` неприменим, статистики
    рынка ЭТП в реестре нет. *Что делать:* завести отдельный мини-набор (ЕИС/Госзакупки,
    ассоциация ЭТП) либо честно держать вкладку «Рынки» на прозе с тегом `суждение`.
11. **DOMRF — особый governance-кейс.** Институт развития, до IPO 100% у государства.
    Стандартная логика «структура собственности / free-float» к нему применяется иначе:
    важны доля РФ, статус госкорпорации и мандат. *Что делать:* не гнать через общий шаблон.
12. **Санкционные эмитенты (SBER, VTBR, SPBE, CBOM) частично прекратили публикацию.** Часть
    раскрытия свёрнута с 2022 г. по постановлению об ограничении раскрытия. ЦБ-формы по ним
    тоже могут публиковаться в усечённом виде. *Что делать:* при пустом поле — `data_flag`
    «раскрытие ограничено», а не `null` без объяснения; проверять полноту формы 101/135
    перед тем, как считать долю рынка.
