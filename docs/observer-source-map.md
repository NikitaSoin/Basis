# Карта источников Обозревателя и шина «поток → карточки» (штурм 2026-07-27)

> Владелец: «подумай глобально, какую информацию тянуть/парсить в Обозреватель
> дополнительно, чтобы входящий поток был системнее и полезнее, и мы могли им
> обновлять карточки компаний (вкладки), не гоняя агентов в веб-серч».
> Это документ-штурм + архитектура. Реализация MVP — company_signals
> (см. app/services/company_signals.py).

## 1. Принцип: три уровня потока

```
УРОВЕНЬ 0 — СЫРЬЁ:      источники → парсеры (news_pipeline, geo_digest,
                        macro_ingest, report_watch, calendar, telegram)
УРОВЕНЬ 1 — СМЫСЛ:      LLM-классификация: тема (macro/geo/inst/sector),
                        важность, пересказ  ← уже есть
УРОВЕНЬ 2 — СИГНАЛЫ:    нормализованные события ПО ТИКЕРУ: тип события +
                        какая ВКЛАДКА карточки затронута + важность + trust
                        ← НОВОЕ (company_signals, эта сессия)
УРОВЕНЬ 3 — ПОТРЕБИТЕЛИ:
   клиент  — блок «Свежее по компании» на карточке, корп-события, Обозреватель
   агенты  — триггер точечного обновления вкладки (по образцу addendum-пилота
             и barometer_reviser: гейт качества, поводок) ← следующий этап
   летопись — chronicle (уже есть)
```

Ключевая идея: карточку обновляет не «агент пошёл в веб-серч за всем подряд»,
а **сигнал достаточной важности** из уже отфильтрованного потока. Веб-серч
остаётся только для верификации конкретного сигнала.

## 2. Карта: какая вкладка карточки чем питается

| Вкладка | Тип сигналов | Источники (есть → добавить) |
|---|---|---|
| **Финансы** | отчётность вышла, guidance, существенные факты | report_watch (есть) → **e-disclosure СФ** |
| **Дивиденды** | рекомендация СД, утверждение ГОСА, отсечка | календарь+Лента (есть) → e-disclosure |
| **Управление** | смена CEO/СД, допэмиссия, buyback, иски, конфликт акционеров | Лента keyword (есть) → e-disclosure СФ, **инсайд-TG (internal, как watch-флаг)** |
| **Рынки (сектор)** | цены/объёмы/регулирование отрасли | — → **отраслевые ленты** (металлы/агро/нефтегаз/порты/банки/ритейл/энерго), OPEC/IEA |
| **Макро** | ставка/инфляция/курс/мир | ЦБ, Росстат, ЦМАКП (есть) → Fed/ECB пресс-RSS |
| **Гео** | СВО/БВ/АТР | geo_digest (есть) → **инсайд-TG (internal)** |
| **Институты** | регулирование, национализация, суды | geo_digest (есть) → **инсайд-TG (internal)** |
| **Облигации эмитента** | рейтинговые действия, дефолты, оферты | smart-lab срез (есть, стареет) → **ленты АКРА/Эксперт РА/НКР/НРА** — самое ценное новое: официальные события по конкретным эмитентам |

Live-проверка кандидатов — docs/audit-2026-07/source-scouting.md (агент-разведчик).

## 3. Уровни доверия источников (эпистемика — конституция)

| Ярус | Источники | Правила |
|---|---|---|
| **Официальные** | e-disclosure, рейтинговые агентства, ЦБ, Росстат, MOEX | сигнал = «факт», может напрямую обновлять данные карточки |
| **Деловые СМИ** | Интерфакс, РБК, Ъ, отраслевые | сигнал = «сообщение», обновляет с атрибуцией |
| **Аналитические** | ЦМАКП, ISW, Economist, Carnegie-TG | контекст для макро/гео/институтов |
| **Инсайдерские TG** | moi_misli_vslukh, insider_best_tg, insider_elites | 🔴 **internal-only + low_trust**: НЕ публикуются клиентам, НЕ могут быть единственным основанием изменения карточки. Роль: (а) watch-флаг «присмотреться к теме», (б) вход для агентов с пометкой «непроверенный инсайд — сверь с официальным», (в) сырьё для барометров/оверлея (там уже стоят гейты) |

Владелец про инсайд-каналы: «любят приукрасить/пафоса нагнать или приврать,
но с точки зрения рисков и подсветки внутрянки полезны — понимаем, куда на
макро-уровне (институты/геополитика/макро) движется». Ровно поэтому low_trust
+ internal: пользуемся как радаром, не как источником фактов.

## 4. Телеграм: что подключено и границы

- `moi_misli_vslukh` — internal-only (решение владельца: не публиковать).
- `insider_best_tg`, `insider_elites` — internal-only + low_trust.
- 🔴 Закрытый канал (инвайт `+pcn1EM9MC4RhOTky`) — **технически недоступен**:
  мы читаем телегу через веб-превью t.me/s/ (только публичные каналы).
  Для закрытых нужен Telegram Client API (Telethon: номер, сессия, серая зона
  ToS) — отдельное решение владельца, в этом контуре не делаем.
- Легальность: пересказ своими словами с пометкой типа источника; прямые
  цитаты и репаблишинг не делаем; серые источники обезличиваются (готовые
  фильтры situation_overlay).

## 5. Что НЕ тянем (осознанно)

- Bloomberg/FT/WSJ — ToS запрещает редистрибуцию, paywall.
- Медуза/RFE и пр. нежелательные/иноагенты — комплаенс РФ (блоклист уже есть).
- DeepState/lostarmour — юр. запрет владельца (уже зафиксирован).
- Платные терминалы (Cbonds, Argus) — нет лицензии.

## 6. Реализация (эта сессия — MVP шины)

1. `company_signals` (таблица): ticker, signal_type, card_tab, importance,
   trust, internal, title, summary, source_key/url, published_at, dedup.
2. Экстракция: (а) market_updates.affected_tickers → прямая конвертация
   (LLM уже отработал в Ленте); (б) geo_digest-статьи (вкл. инсайд-TG) →
   LLM-батч «какие тикеры/вкладки затронуты»; дедуп по (ticker, type, окно).
3. internal-флаг на статьях digest: инсайд-каналы хранятся, питают агентов
   и барометры, но НЕ отдаются публичными эндпоинтами.
4. API: GET /companies/{ticker}/signals (только public-сигналы).
5. Кроны: экстракция после ленты и дайджеста; ретеншен.

## 7. Следующие этапы (очередь)

- **Consumer-агент**: сигнал importance≥high по тикеру → точечный addendum
  вкладки (расширение macro_addendum-пилота на новые типы; гейт как у
  barometer_reviser). Это закрывает «карточки обновляются сами».
- Подключение топ-источников из разведки (рейтинговые агентства — первыми).
- Блок «Свежее по компании» на карточке (public-сигналы).
- Решение владельца по Telethon для закрытых каналов.

## 8. Статус MVP (2026-07-27, на бою) + известное ограничение

Шина `company_signals` задеплоена и прогнана: первый прогон — 745 сигналов из
Ленты + 4 из дайджеста, размечены по вкладкам, инсайд-каналы скрыты из
публичных эндпоинтов (проверено: institutions/digest не содержит insider-меток).

🔴 ИЗВЕСТНОЕ ОГРАНИЧЕНИЕ ТОЧНОСТИ (для consumer-этапа): привязка «новость →
тикер» из Ленты ШИРОКАЯ (affected_tickers = «затронуто», не «событие ПО
эмитенту»), а keyword-классификатор вкладки ловит слова по всему тексту.
Живые ложные срабатывания на SBER: «ЦБ ужесточил кредиты» → повешено как
событие Сбера (это макро сектора); «дивиденды Русагро: дайджест» → SBER
dividends/high (слово «дивиденд» в общем заголовке, тикер широкий). Для
витрины «Свежее по компании» терпимо (связанные новости). Для АВТОТРИГГЕРА
обновления вкладки — НЕТ: consumer-агент ОБЯЗАН верифицировать сигнал
(прямая привязка к эмитенту + верная вкладка + порог importance), не доверять
keyword-вкладке слепо. Ужесточение маппинга (главный тикер новости, а не все
«затронутые»; вкладка из события, не из слова) — часть consumer-этапа.
