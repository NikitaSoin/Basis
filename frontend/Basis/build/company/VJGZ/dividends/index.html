Дивиденды: ННК-Варьеганнефтегаз (VJGZ)

Последняя выплата — 0,5 ₽ на акцию за 2025 год. Дивиденды выплачивались 2 года из 7.

Дивидендная политика

Формализована только дивидендная формула по привилегированным акциям (10% чистой прибыли / число префов, с правилом выравнивания под обыкновенную акцию). По обыкновенным акциям предсказуемой дивидендной политики нет: выплаты по усмотрению собрания, на практике отсутствуют.

Гарантированного минимума по обыкновенным нет. По префу формула привязана к чистой прибыли года; периодичность — годовая; выплаты нерегулярны.

Насколько выплаты регулярны

Нерегулярные. За 2019–2025 гг. подтверждённая выплата по префу — только 2019 (3,02 ₽) и символические 0,5 ₽ за 2025; по обыкновенным выплат нет вовсе. Многолетняя пауза 2020–2024.

Политика и практика

Разрыв между формулой и практикой большой. Формула по префу существует, но выплаты разрежены и малы (3,02 ₽ за 2019, затем пауза, 0,5 ₽ за 2025). По обыкновенным дивидендов фактически нет. Чистая прибыль волатильна и, по признакам, занижается трансфертными расчётами внутри группы ННК (РСБУ-прибыль против МСФО-убытка), что делает формульный дивиденд по префу непредсказуемым и близким к нулю. Для миноритария — слабая дивидендная защита.

Что стоит за отдельными годами

  • 2025 — По итогам 2025 СД рекомендовал: по обыкновенным — без выплат, по префу VJGZP — символические 0,5 ₽; реестр под выплату по префу — 13.07.2026.
  • 2024 — По итогам 2024 — без выплат по обоим классам. Год убытка по МСФО (−4 450 млн), формульная база по префу = 0 — пропуск формально оправдан, но убыток сам по себе — следствие трансфертного перераспределения маржи вверх.
  • 2023 — Выплат нет, при этом 2023 — год прибыли (ЧП 11,8 млрд). Пропуск при наличии прибыли — решение мажоритария не распределять; сигнал.
  • 2022 — Выплат нет. МСФО за 2022 в агрегаторе отсутствует — результат не верифицируем, но дивиденд не объявлялся.
