🔴 **Старый диагноз (оставлен для истории):** `_revenue_per_share`
считает выручку на акцию как `meta.last_price / multiples.current.ps`. Формула сама по
себе единично-безопасна (P/S безразмерен), НО берёт ЦЕНУ ИЗ ФАЙЛА. У SGZH там
`last_price: 3413 ₽` при реальной цене ~0,53 ₽ → выручка на акцию 4266 ₽ вместо
фактических ~1,14 ₽ (89,2 млрд выручки / 78,45 млрд акций) — завышение в тысячи раз,
отсюда потенциал +26830 %. Лечится либо кросс-проверкой с `revenue_total·1e6/shares`
(брать меньшее/медиану при расхождении в разы), либо пересчётом P/S от живой цены.
Проверить заодно, у скольких ещё компаний `meta.last_price` разошёлся с живой ценой —
через ту же формулу он течёт в BFV-F у всех.

## Бизнес-контекст (неизменное)
Независимый аналитический слой и «второе мнение» для самостоятельного частного
инвестора: цельная картина (компания, рынок, макро, гео, портфель) вместо тумана.
НЕ брокер, не сделки, не «купить/продать». Снижает неопределённость, не хайп.
Ценность — доверие, логика, полнота рассуждений.
