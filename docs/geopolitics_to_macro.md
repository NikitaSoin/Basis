# ЧАСТЬ 0. КАК ПОЛЬЗОВАТЬСЯ

## 0.1. Главный вопрос

Агент каждый раз отвечает на один и тот же вопрос:

> **Как это событие меняет ограничения, стимулы и потоки ресурсов в экономике России,
> через какие каналы это доходит до макропеременных, с какими лагами, и как на это
> ответит государство?**

## 0.2. Универсальная цепочка

```
ГЕОПОЛИТИЧЕСКОЕ СОБЫТИЕ
      ↓
ИЗМЕНЕНИЕ УСЛОВИЙ         (физических, финансовых, институциональных)
      ↓
ЭКОНОМИЧЕСКИЕ КАНАЛЫ      (14 каналов, Часть 2)
      ↓
МАКРОПЕРЕМЕННЫЕ           (инфляция, ВВП, курс, бюджет, ставка)
      ↓
РЕАКЦИЯ ГОСУДАРСТВА И ЦБ  (фискальная, монетарная, административная)
      ↓
ИЗМЕНЕНИЕ ПОВЕДЕНИЯ ЧАСТНОГО СЕКТОРА
      ↓
ВТОРИЧНЫЕ ЭФФЕКТЫ → новый ответ политики → ...
```

Конструкция **рекурсивная**: результат — не «шок → экономика», а несколько витков
«шок → реакция → адаптация → новая реакция».

## 0.3. Пять фиксаций перед началом анализа

Без них анализ будет неверным независимо от качества дальнейших рассуждений.

| № | Что зафиксировать | Почему критично |
|---|---|---|
| 1 | **Событие** — что именно произошло | «Обострение» — не событие. Событие: конкретное решение, атака, введение ограничения |
| 2 | **Роль России** — участник / союзник / объект вторичных мер / контрагент / наблюдатель | определяет, начинать с бюджета или с мировых рынков |
| 3 | **Горизонт** — дни / месяцы / 1–3 года / 3–10 лет | один шок может повышать ВВП сейчас и снижать потенциал потом |
| 4 | **Исходный режим** — инфляция, рынок труда, цена нефти, жёсткость ДКП, дефицит бюджета, запас мощностей | один и тот же шок в перегреве и в недогреве даёт разный результат |
| 5 | **Контрфакт** — что было бы без события | без него эффект будет завышен (см. 0.4) |

## 0.4. Контрфакт — обязательное правило

Эффект измеряется не «до и после», а относительно сценария без события:

```
Δ Эффект = X (с событием) − X (базовый сценарий без события)
```

**Пример.** Нефть выросла с $70 до $85 после начала конфликта. Но без конфликта она
росла бы до $80 на восстановлении спроса. Геополитический эффект = **+$5, а не +$15**.

Без контрфакта агент будет систематически приписывать геополитике всё, что происходит в
экономике одновременно с ней.

## 0.5. Не задавать знак заранее — главное методологическое правило

Один и тот же шок может одновременно:

```
+ повышать ВВП          (через госрасходы)
− снижать потенциал     (через дефицит труда и инвестиционный спад)
+ повышать выручку      (через цены на сырьё)
− повышать инфляцию     (через курс и издержки)
− повышать ставку       (как реакцию ЦБ)
```

Задача агента — **не выбрать один эффект, а построить их сеть** и определить, какие
доминируют на каждом горизонте. Формулировки «война хороша для экономики» или «война
плоха для экономики» одинаково непрофессиональны.

## 0.6. Порядки эффектов — обязательная разметка

| Порядок | Что это | Пример |
|---|---|---|
| **Первый** | непосредственное изменение | боевые действия → оборонные расходы ↑ |
| **Второй** | реакция экономики | расходы ↑ → дефицит труда ↑ → зарплаты ↑ |
| **Третий** | ответ экономической политики | зарплаты ↑ → инфляция ↑ → ставка ЦБ ↑ → кредит ↓ → инвестиции ↓ |
| **Четвёртый** | долгосрочное следствие | инвестиции ↓ → потенциальный ВВП ↓ |

Большинство ошибок — остановка на первом порядке. Настоящий результат обычно
формируется на третьем и четвёртом.

## 0.7. Как размечать каждый эффект

По каждому эффекту фиксируем шесть параметров:

| Параметр | Значения |
|---|---|
| **Тип** | прямой / косвенный |
| **Порядок** | первый / второй / третий / четвёртый |
| **Направление** | знак для конкретной переменной |
| **Сила** | класс масштаба: малый / умеренный / значимый / режимный |
| **Лаг** | дни / месяцы / кварталы / годы |
| **Обратимость** | быстро обратим / медленно / гистерезис / необратим |

Последний параметр — самый упускаемый и самый важный для сценариев мира (Часть 6).

# ЧАСТЬ 1. СОБЫТИЕ, РОЛЬ РОССИИ, ИНТЕНСИВНОСТЬ

## 1.1. Типы событий

| Категория | Примеры |
|---|---|
| **Военные** | начало конфликта, эскалация боевых действий, мобилизация, расширение географии, удары по инфраструктуре |
| **Санкционные** | новые ограничения, расширение списков, ужесточение правоприменения, вторичные санкции |
| **Торговые** | закрытие маршрута, экспортный контроль, пошлины, эмбарго, ценовой потолок |
| **Коалиционные** | вступление третьих стран, распад или укрепление коалиции, смена позиции ключевого партнёра |
| **Деэскалационные** | перемирие, мирное соглашение, частичное снятие ограничений, размораживание активов |
| **Институциональные** | конфискация активов, изменение правового режима, выход из международных структур |

## 1.2. Пять конфигураций участия России

От этого зависит, с какого конца начинать анализ.

| Конфигурация | Откуда начинать | Доминирующие каналы |
|---|---|---|
| **1. Непосредственный участник** | с бюджета и рынка труда | фискальный, труд, санкции, инфраструктура |
| **2. Участник через союзника** | с рисков вторичных мер | санкции, расчёты, риск-премия |
| **3. Объект вторичных санкций** | с расчётов и логистики | платежи, торговля, дисконт |
| **4. Экономический контрагент сторон** | с торговых потоков | торговля, terms of trade |
| **5. Внешний наблюдатель** | **с мировых рынков, а не с России** | сырьё, глобальный спрос, мировые ставки |

**Критично:** при конфигурации 5 нельзя начинать с «конфликт → российский бюджет».
Цепочка идёт: конфликт → глобальная переменная → Россия. Это принципиально другая логика
(Часть 8).

## 1.3. Вектор интенсивности — вместо одной шкалы «сильнее/слабее»

Интенсивность конфликта — не одно число, а восемь независимых измерений. Каждое может
двигаться самостоятельно, и у каждого свои экономические каналы.

| Ось | Что измеряет | Главный экономический канал |
|---|---|---|
| **K** — боевая интенсивность | масштаб военных действий | расход боеприпасов и техники → госрасходы |
| **M** — мобилизация ресурсов | вовлечение людей и мощностей | рынок труда, вытеснение гражданского сектора |
| **G** — география | где идут действия | инфраструктура, логистика |
| **S** — санкционное давление | масштаб экономических ограничений | торговля, дисконт, расчёты |
| **T** — технологические ограничения | доступ к оборудованию и технологиям | производительность, потенциальный ВВП |
| **F** — финансовые ограничения | доступ к капиталу, расчётам, резервам | платежи, риск-премия, курс |
| **R** — нарушение инфраструктуры | ущерб критическим объектам | предложение, издержки |
| **C** — вовлечённость третьих стран | число и глубина участия | глобальные каналы, вторичные санкции |

**Зачем это нужно.** Возможна ситуация: боевая интенсивность растёт (K↑), а санкционное
давление не меняется (S=), потому что основные ограничения уже введены. Тогда
экономический эффект эскалации идёт почти целиком через бюджет и труд, а не через
торговлю. Одна шкала «уровень войны» этого не покажет.

## 1.4. Лестница эскалации: что уже применено, что осталось

Это прямое следствие принципа остаточной экспозиции (Часть 3). Прежде чем оценивать
риск эскалации, надо понять, **что ещё может быть применено**.

| Мера | Типовой статус | Остаточный потенциал ущерба |
|---|---|---|
| Ограничения на отдельные компании | применено широко | средний — остаются неохваченные |
| Отключение от расчётной инфраструктуры | применено к части банков | зависит от охвата оставшихся |
| Заморозка государственных резервов | применено | низкий — уже реализовано |
| Ценовой потолок на экспорт | применено к части товаров | средний — параметры могут ужесточаться |
| Эмбарго на импорт российских товаров | применено к части направлений | зависит от оставшейся торговли |
| Экспортный контроль на технологии | применено | средний — расширение перечней |
| **Вторичные санкции на третьи страны** | применяется выборочно | **высокий — главный оставшийся рычаг** |
| Конфискация (а не заморозка) активов | обсуждается | высокий, но с обратным эффектом на доверие |
| Ограничения на теневую логистику | усиливается | высокий |

**Правило:** ущерб от эскалации ограничен тем, что ещё не обнулено. Если канал уже
закрыт на 90%, его повторное закрытие почти ничего не меняет — и наоборот, живой канал с
большой экспозицией несёт основной риск.

# ЧАСТЬ 2. КАНАЛЫ ПЕРЕДАЧИ

Ядро методички. Четырнадцать каналов. По каждому: механизм, что смотреть, лаг,
обратимость, типичные ошибки.

**Правило:** агент обязан пройти по всем каналам и явно сказать, какие задействованы, а
какие нет. Пропуск канала без объяснения = незавершённый анализ.

## 2.1. Фискальный канал

**Механизм.**

```
Военные и силовые расходы ↑
   → совокупный спрос ↑
   → при ограниченных мощностях: инфляция ↑ больше, чем выпуск ↑
   → одновременно ресурсы перетекают из гражданского сектора в государственный
```

**Что раскладывать — четыре группы расходов:**

| Группа | Состав | Экономический эффект |
|---|---|---|
| Прямые военные | вооружение, боеприпасы, техника, военная инфраструктура | заказ конкретным предприятиям, часто непубличным |
| Личный состав | довольствие, компенсации, выплаты семьям | прямой рост доходов домохозяйств → потребление |
| Силовой контур | внутренняя безопасность, охрана инфраструктуры | занятость, не создающая продукт |
| Косвенные | субсидии предприятиям, поддержка регионов, восстановление, льготное кредитование | размывают границу бюджета и квазибюджета |

**Как финансируется — определяет макроэффект:**

| Источник | Эффект |
|---|---|
| Налоги | изъятие у частного сектора → сдерживает спрос, но бьёт по инвестициям |
| Заимствования | рост предложения госбумаг → доходности ↑ → стоимость капитала ↑ для всех |
| Сокращение других расходов | перераспределение, нейтрально для спроса |
| Использование резервов | нейтрально к рынку, но исчерпаемо |
| Прямое денежное финансирование | максимально проинфляционно |

**Важное различение, которое часто путают:**

```
Покупка госбумаг центральным банком на вторичном рынке
   ≠ прямое денежное финансирование бюджета
   ≠ операции по управлению ликвидностью
```

Это три разных механизма с разными инфляционными последствиями. Агент не должен
схлопывать их в «напечатали денег».

**Что смотреть:** структура расходов по разделам, дефицит, объём размещений госбумаг,
стоимость новых заимствований, процентные расходы бюджета, срочность долга.

**Лаг:** решение → расходование 1–2 квартала; расходы → спрос 1–2 квартала.

**Обратимость:** низкая. Оборонные расходы липкие вниз: за ними стоят контракты,
занятость в моногородах, наращённые мощности. После снижения интенсивности расходы
падают медленнее, чем выросли, — **фискальный храповик**.

**Ошибки:** останавливаться на «расходы выросли, спрос вырос»; не проверять, доходит ли
импульс до публичных компаний (значительная часть оборонного заказа идёт в непубличный
контур); игнорировать вытеснение гражданского сектора.

## 2.2. Рынок труда и демография

**Механизм — двусторонний, и в этом главная опасность:**

```
ПРЕДЛОЖЕНИЕ ТРУДА ↓                    СПРОС НА ТРУД ↑
  мобилизация                            оборонные предприятия
  эмиграция                              силовой сектор
  потери и инвалидизация                 строительство, логистика
  уход в силовой сектор                  госзаказ

           → конкуренция за работника резко растёт
           → зарплаты растут быстрее производительности
           → удельные трудовые издержки ↑ → инфляция ↑
```

**Ключевая формула:**

```
Инфляционное давление от труда ≈ Рост зарплат − Рост производительности
```

Если зарплаты растут на 15%, а производительность на 2% — 13 п.п. давят на издержки и
цены по всей экономике.

**Три эффекта, которые обычно упускают:**

**1. Композиция важнее количества.** Уходит не абстрактная «единица труда», а мужчины
25–45 лет с конкретными навыками. Потеря 1% рабочей силы такого профиля бьёт сильнее,
чем 1% в среднем, потому что именно эта группа несёт квалифицированное производство,
строительство и транспорт.

**2. Военные выплаты как якорь зарплат.** Высокие выплаты определённой категории
переустанавливают представления о «нормальной» зарплате по всей экономике. Работники
гражданских отраслей требуют компенсации разрыва → зарплатная спираль запускается даже
там, где нет прямого дефицита кадров.

**3. Эмиграция селективна.** Уезжают более молодые, мобильные и квалифицированные.
Поэтому падает не только количество, но и **качество** рабочей силы, а это уже удар по
производительности — то есть по потенциальному ВВП, а не по текущему выпуску.

**Компенсирующий фактор:** трудовая миграция. Её объём чувствителен к курсу рубля (через
ценность переводов на родину) и к политическим отношениям со странами-донорами. Ослабление
рубля сокращает приток мигрантов — это усиливает дефицит.

**Что смотреть:** безработица, число вакансий, отношение вакансий к безработным, рост
номинальных зарплат, производительность, миграционное сальдо, доля занятых в силовом и
оборонном секторе.

**Лаг:** на зарплаты 1–2 квартала; на инфляцию 2–4 квартала; на производительность годы.

**Обратимость:** **гистерезис**. Демобилизация возвращает часть людей, но не возвращает
эмигрировавших, не восстанавливает утраченные навыки и не отменяет инвалидизацию.
Зарплатные ожидания, однажды поднятые, вниз не идут.

## 2.3. Санкционный канал: типология и правоприменение

**Главный принцип:** санкция — это не переменная, а механизм ограничения ресурсов. Эффект
считается не по факту введения, а по фактической доступности ресурса.

```
Санкция → юридический запрет
        → поведение контрагентов (главное!)
        → фактическая доступность товара/услуги/расчёта
        → экономический эффект
```

**Типология — разные типы бьют по-разному:**

| Тип | Механизм | Основной удар |
|---|---|---|
| **Персональные / блокирующие** | заморозка активов, запрет операций с лицом | точечный, но с эффектом заражения контрагентов |
| **Секторальные** | ограничение операций в отрасли | доступ к капиталу и технологиям сектора |
| **Экспортный контроль** | запрет на поставку технологий | производительность, потенциальный ВВП |
| **Импортное эмбарго** | запрет покупателям приобретать товар | объём экспорта, переориентация |
| **Ценовой потолок** | разрешает торговлю ниже установленной цены | **дисконт, а не объём** |
| **Финансовые** | отключение от расчётов, заморозка резервов | платежи, ликвидность, курс |
| **Вторичные** | угроза санкций третьим странам | **самый сильный: меняет поведение нейтральных сторон** |

**Правоприменение важнее текста — ключевой механизм.**

```
Формально разрешено, но:
   банк-контрагент боится вторичных санкций
   → отказывается проводить платёж
   → перестраховывается сверх требований
   → фактический эффект СИЛЬНЕЕ юридического запрета
```

Это явление сверхсоблюдения — основной источник ущерба в современных санкционных режимах.
Поэтому агент обязан различать:

| Что смотреть | Вопрос |
|---|---|
| Формальное ограничение | что запрещено буквально |
| Правоприменительная практика | преследуют ли за нарушение, были ли прецеденты |
| Поведение контрагентов | берутся ли банки, перевозчики, страховщики за операции |
| Фактическая доступность | проходят ли сделки в реальности и по какой цене |

**Проверочный список для оценки реального эффекта:**

- есть ли альтернативный поставщик и на каких условиях;
- существует ли отечественный аналог и какого качества;
- возможен ли параллельный импорт и с какой наценкой;
- сколько времени занимает перестройка цепочки;
- насколько выросла цена и ухудшилось качество;
- есть ли критическая зависимость от одной страны.

**Главный вывод:** санкция ≠ автоматическая потеря производства. Чаще это **удорожание и
ухудшение качества**, а не остановка. Оценивать надо степень переноса, а не факт запрета.

---

## 2.4. Клин цены — центральная переменная санкционного давления

Это канал, который для России часто важнее объёмного. Формулируется отдельно, потому что
его регулярно упускают.

**Механизм.**

```
Мировая цена товара
   − скидка к бенчмарку (санкционный дисконт)
   − удорожание логистики (длинное плечо, нестандартные маршруты)
   − удорожание страхования (или самострахование)
   − издержки расчётов (комиссии, задержки, посредники)
   − маржа посредников
   = ЧТО РЕАЛЬНО ПОЛУЧАЕТ ЭКОНОМИКА
```

Разница между первой и последней строкой — **клин**. Он и есть измеритель санкционного
давления.

**Почему это важнее объёма:**

| Показатель | Что показывает | Обманчивость |
|---|---|---|
| Физический объём экспорта | сколько вывезли | может не падать вовсе |
| Валютная выручка | сколько выручили | падает сильнее объёма |
| **Нетбэк (что дошло)** | **сколько досталось** | **истинный измеритель** |

**Пример.** Объём экспорта не изменился, мировая цена не изменилась, но дисконт вырос на
$10/барр, а логистика подорожала на $5/барр. Физически всё в порядке, а бюджет и компании
недополучают $15 с каждого барреля. В статистике объёмов это не видно вообще.

**Что смотреть:** спред между национальной экспортной котировкой и мировым бенчмарком,
стоимость фрахта на ключевых маршрутах, страховые ставки, длина логистического плеча,
задержки платежей.

**Обратимость:** **средняя и относительно быстрая**. Дисконт сужается при снятии
ограничений быстрее, чем восстанавливаются объёмы и доли рынка. Это один из немногих
каналов, где деэскалация даёт быстрый эффект.

---

## 2.5. Расчёты, платежи и репатриация выручки

Отдельный канал, потому что экспорт может состояться, а деньги — не дойти.

**Механизм.**

```
Ограничения на расчёты
   → удлинение платёжных цепочек, посредники
   → задержки поступления выручки
   → часть выручки в неконвертируемых валютах
   → выручка не конвертируется в рубли
   → НЕ поддерживает курс, НЕ поступает в бюджет вовремя
```

**Три отдельных эффекта:**

| Эффект | Механизм | Макропоследствие |
|---|---|---|
| Задержка расчётов | длинные цепочки, проверки | разрыв между отгрузкой и поступлением валюты → давление на курс в моменте |
| Неконвертируемые остатки | выручка в валюте с ограниченной конвертацией | формально есть, экономически недоступна |
| Издержки посредников | комиссии за обход ограничений | вычет из нетбэка (см. 2.4) |

**Что смотреть:** сроки поступления экспортной выручки, структура валют расчёта, объём
и доступность зарубежных остатков, комиссии за трансграничные операции.

**Обратимость:** высокая при снятии ограничений — расчётная инфраструктура
восстанавливается быстрее физической.

---

## 2.6. Валютный канал

**Механизм — предложение против спроса на валюту:**

```
ПРЕДЛОЖЕНИЕ ВАЛЮТЫ            СПРОС НА ВАЛЮТУ
  экспортная выручка            импорт
  репатриация                   отток капитала
  приток капитала               накопление валютных активов
                                обслуживание внешних обязательств
```

Плюс модификаторы: реальная ставка, премия за риск, ожидания, валютное регулирование,
операции по бюджетному правилу.

**Два эффекта, конфликтующих между собой:**

```
Ослабление рубля → импорт дорожает → инфляция ↑        (плохо)
Ослабление рубля → рублёвая экспортная выручка ↑        (хорошо для бюджета)
```

Отсюда систематический конфликт: слабый рубль помогает свести бюджет, но мешает ЦБ
удерживать инфляцию. При военном бюджетном импульсе этот конфликт обостряется.

**Специфика военного времени:** перенос курса в цены **выше обычного**, потому что
инфляционные ожидания расшатаны, а конкуренция ослаблена (см. 2.13). То есть одна и та же
девальвация даёт больший инфляционный эффект, чем в спокойный период.

**Обратимость:** курс сам по себе обратим быстро; накопленный перенос в цены — нет
(цены «липкие вниз»).

---

## 2.7. Сырьевой канал и условия торговли

**Базовая цепочка:**

```
Конфликт → мировой баланс спроса и предложения → мировая цена
        → экспортная выручка → бюджет, курс, торговый баланс
```

**Обязательное разложение на два эффекта:**

```
Выручка = Цена × Объём

Возможны все комбинации:
   Цена ↑, Объём ↑  → однозначный плюс
   Цена ↑, Объём ↓  → неопределённо, считать произведение
   Цена ↓, Объём ↑  → неопределённо
   Цена ↓, Объём ↓  → однозначный минус
```

**Условия торговли — центральный внешний показатель:**

```
Условия торговли = Индекс экспортных цен / Индекс импортных цен
```

Если экспортные цены растут быстрее импортных — страна получает внешний выигрыш, даже
без изменения физических объёмов. Для сырьевой экономики это главный измеритель внешнего
геополитического шока.

**Важная поправка для России:** при санкционном режиме мировая цена и полученная цена
расходятся (см. 2.4). Поэтому в расчёте условий торговли надо использовать **фактические
экспортные цены с учётом дисконта**, а не мировые котировки.

---

## 2.8. Технологии, импорт и производительность

**Механизм — самый долгосрочный из всех:**

```
Ограничение доступа к технологиям
   → дефицит оборудования и компонентов
   → замещение худшим аналогом или отказ от проекта
   → снижение производительности
   → снижение потенциального ВВП
```

**Что оценивать:**

| Вопрос | Почему важен |
|---|---|
| Критичность технологии | есть ли что-то, что нельзя заменить в принципе |
| Наличие аналога и разрыв в качестве | замещение редко бывает равноценным |
| Время перестройки цепочки | месяцы или годы |
| Удорожание | параллельный импорт с наценкой |
| Глубина зависимости | доля критичных компонентов от одного источника |

**Ключевое различие:** ограничение бьёт не по текущему выпуску (запасы, обходные пути),
а по **обновлению основных фондов**. Эффект проявляется через годы, когда наступает срок
замены оборудования, а замены нет.

**Обратимость:** **низкая, с гистерезисом**. Даже при снятии ограничений упущенное
технологическое поколение не догоняется автоматически: конкуренты ушли вперёд,
компетенции утрачены, поставщики переориентированы.

---

## 2.9. Инвестиции и неопределённость

**Два независимых механизма:**

```
1. ЧЕРЕЗ СТОИМОСТЬ КАПИТАЛА
   премия за риск ↑ → стоимость капитала ↑ → проекты не окупаются → инвестиции ↓

2. ЧЕРЕЗ НЕОПРЕДЕЛЁННОСТЬ (ценность ожидания)
   неопределённость ↑ → выгодно подождать и посмотреть → решение откладывается
   → инвестиции ↓ ДАЖЕ при неизменной ожидаемой доходности
```

Второй механизм часто сильнее первого и почти всегда упускается. При высокой
неопределённости рациональное поведение — отложить необратимое решение, поэтому падают
именно длинные и капиталоёмкие проекты.

**Кто страдает сильнее:**

| Профиль проекта | Уязвимость |
|---|---|
| Длинный срок окупаемости | максимальная |
| Импортное оборудование | максимальная |
| Капиталоёмкий | высокая |
| Короткий цикл, быстрая окупаемость | низкая |

**Следствие для структуры экономики:** выживают и растут секторы «сегодняшнего дня», а
секторы с длинным CAPEX сжимаются. Это меняет структуру экономики в пользу
низкопроизводительных быстрых бизнесов — удар по долгосрочному росту.

**Обязательное разделение:**

```
Частные инвестиции ↓   (неопределённость, стоимость капитала)
Государственные ↑      (оборона, инфраструктура)

Совокупные инвестиции могут не измениться —
но их КАЧЕСТВО и отдача меняются радикально
```

---

## 2.10. Финансовый канал и премия за риск

**Механизм:**

```
Геополитический риск ↑
   → премия за риск ↑
   → доходности растут, спреды расширяются
   → стоимость капитала ↑ → оценка активов ↓ → инвестиции ↓
```

**Отдельный элемент — права собственности.** Заморозка и конфискация активов работают в
обе стороны (активы страны за рубежом, иностранные активы внутри страны) и создают
**постоянную надбавку к страновой премии за риск**. Это не циклический, а структурный
сдвиг: он остаётся в оценке даже после нормализации, потому что прецедент создан.

**Что смотреть:** доходности госбумаг, корпоративные спреды по эшелонам, стоимость
страхования риска, доступность внешнего финансирования, отток капитала.

**Обратимость:** премия за риск сжимается быстро при деэскалации — это один из самых
быстрых каналов. Но её «этаж» после конфликта выше довоенного из-за прецедента с правами
собственности.

---

## 2.11. Физическая инфраструктура

**Механизм.** Ущерб критическим объектам снижает предложение и повышает издержки.

**Правило оценки — не «объект повреждён», а четыре множителя:**

```
Эффект = Мощность объекта
       × Доля объекта в национальной системе
       × (1 − Возможность замещения)
       × Время восстановления
```

**Ключевая асимметрия:**

| Ситуация | Эффект |
|---|---|
| Повреждено 10% мощности, есть резерв | эффект существенно меньше 10% |
| Повреждено 2%, но это узкое место без обхода | эффект **непропорционально велик** |

Поэтому важна не доля мощности, а положение объекта в цепочке: узел без обходного пути
критичнее крупного объекта с резервированием.

**Категории критических объектов:** переработка топлива и нефтебазы, трубопроводы,
генерация и электросети, железнодорожные узлы и мосты, порты и аэропорты, логистические
центры и склады, предприятия химии, металлургии и пищевой промышленности, объекты связи.

**Вторичный эффект, который упускают:** повреждение переработки при сохранной добыче
означает не падение экспорта нефти, а **дефицит топлива внутри страны** → рост цен на
топливо → удорожание всей логистики → рост издержек по широкому кругу товаров →
инфляционное давление. Один узкий объект даёт общеэкономический эффект.

**Обратимость:** зависит от типа. Склады и нефтебазы восстанавливаются месяцами; сложное
технологическое оборудование при ограничении импорта — годами или не восстанавливается.

---

## 2.12. Институциональная среда, конкуренция, монополизация

**Механизм — самый недооценённый долгосрочный канал:**

```
Конфликт и санкции
   → уход иностранных компаний
   → рост доли государства и госзаказа
   → поглощение слабых компаний сильными в кризис
   → концентрация рынков ↑
   → конкурентное давление ↓
   → стимулы к росту производительности и инновациям ↓
   → долгосрочный темп роста ↓
```

**Почему это макроэкономический, а не отраслевой вопрос.** Конкуренция — один из
механизмов, заставляющих компании снижать издержки и повышать качество. Ослабление
конкуренции означает, что тот же объём ресурсов даёт меньший выпуск.

**Влияние на денежную политику — важное следствие.** Чем больше в экономике
административных цен, субсидий, госзаказа и нерыночного кредитования, тем хуже работает
трансмиссия ДКП:

```
Ставка растёт, но:
   часть заёмщиков получает субсидированный кредит → не реагирует
   часть цен административно регулируется → не реагирует
   → для того же охлаждения инфляции нужна БОЛЕЕ ЖЁСТКАЯ политика
```

То есть институциональный сдвиг меняет **параметры** макромодели, а не только её
переменные (см. 2.14).

**Обратимость:** очень низкая. Изменённая структура собственности, ушедшая конкуренция и
выстроенные административные механизмы не откатываются автоматически при деэскалации.

---

## 2.13. Ожидания и поведение

**Механизм.** Геополитический шок меняет ожидания раньше, чем реальные переменные.

| Субъект | Типичная реакция |
|---|---|
| Домохозяйства | рост сбережений из предосторожности; ажиотажные покупки товаров длительного пользования; переход в валюту и наличные; спрос на ликвидность |
| Компании | накопление запасов; ускорение импорта «пока можно»; откладывание инвестиций; смена поставщиков; превентивное повышение цен |
| Финансовый рынок | дисконтирование будущего шока заранее |

**Следствие:** рыночный эффект возникает **до** физического. Цены активов реагируют на
ожидание события, а не на само событие. Поэтому реализация ожидаемого события может дать
нулевую или обратную реакцию рынка — оно уже в цене.

**Самое важное для инфляции:** расшатывание инфляционных ожиданий. Когда бизнес и
население перестают верить в возврат инфляции к цели, они закладывают рост цен в прайсинг
и зарплаты — инфляция становится самоподдерживающейся, и требуется гораздо более жёсткая
политика.

---

## 2.14. Изменение самих эластичностей (мета-канал)

Отдельный канал, потому что он меняет не значения переменных, а **правила**, по которым
работает вся остальная модель.

| Параметр модели | Как меняется в конфликте | Следствие |
|---|---|---|
| Перенос курса в цены | **растёт** (ожидания расшатаны, конкуренция слабее) | та же девальвация даёт больше инфляции |
| Трансмиссия ДКП | **слабеет** (льготное кредитование, административные цены, госзаказ) | нужна более жёсткая ставка для того же эффекта |
| Эластичность импорта по курсу | **падает** (критичный импорт покупают по любой цене) | девальвация хуже балансирует торговлю |
| Мультипликатор госрасходов | **падает** (нет свободных мощностей и рабочих рук) | тот же импульс даёт больше инфляции и меньше выпуска |
| Реакция предложения на цену | **слабеет** (ограничения на оборудование) | ценовой сигнал не приводит к росту производства |

**Практический вывод.** Нельзя применять довоенные коэффициенты к военному режиму. Если
агент использует эластичность, оценённую в спокойный период, он систематически
недооценивает инфляционные последствия и переоценивает эффективность политики.

# ЧАСТЬ 3. СЕКТОРАЛЬНАЯ ПОЛИТИЧЕСКАЯ ЭКСПОЗИЦИЯ

Это модуль, отвечающий на вопрос: **что уже потеряно, что ещё можно потерять и что может
вернуться**. Без него агент будет пугать инвестора рисками, которые давно реализованы, и
не заметит живых.

## 3.1. Три величины, которые надо различать

По каждому значимому экспортному или импортному потоку:

| Величина | Что означает | Зачем нужна |
|---|---|---|
| **База** | объём и условия до конфликта | точка отсчёта |
| **Текущее состояние** | что осталось сейчас | реальная картина |
| **Остаточная экспозиция** | сколько ещё можно потерять | **измеряет риск эскалации** |
| **Возвратный потенциал** | сколько реально вернётся при деэскалации | **измеряет выгоду от мира** |

**Ключевая асимметрия:**

```
Остаточная экспозиция мала  →  эскалация по этому каналу почти не повредит
Возвратный потенциал мал    →  мир по этому каналу почти не поможет

Это РАЗНЫЕ величины. Канал может быть обнулён (нечего терять),
но при этом невозвратен (некуда вернуться).
```

## 3.2. Почему возвратный потенциал меньше базы — механизм замещения

Когда экспортёр уходит с рынка, его долю занимает конкурент. И это не пассивное
замещение, а **инвестиционное закрепление**:

```
Уход поставщика
   → покупатель ищет замену
   → конкурент подписывает долгосрочный контракт
   → конкурент строит мощности и инфраструктуру под этот контракт
   → покупатель строит приёмную инфраструктуру под нового поставщика
   → регуляторная и политическая рамка закрепляет диверсификацию
   → возврат прежнего поставщика становится дорогим и медленным
```

**Отсюда правило:** чем дольше длится разрыв и чем капиталоёмче замещение, тем меньше
возвратный потенциал. Год отсутствия — обратимо; пять лет с построенными терминалами и
подписанными контрактами на 15–20 лет — почти нет.

**Что проверять при оценке возврата:**

| Вопрос | Что означает ответ |
|---|---|
| Кто занял долю? | если конкурент с длинными контрактами — возврат затруднён |
| Вложил ли он капитал? | окупаемость привязывает покупателя на годы |
| Построил ли покупатель инфраструктуру под альтернативу? | физическое закрепление |
| Есть ли политическое обязательство диверсификации? | регуляторный барьер сверх экономики |
| Сохранилась ли физическая возможность поставки? | инфраструктура могла быть повреждена или законсервирована |

## 3.3. Реестр по направлениям

Ниже — шаблон анализа. Конкретные объёмы агент подставляет из актуальных данных; здесь
зафиксирована **логика оценки** по каждому направлению.

### Трубопроводный газ в Европу

| Параметр | Оценка |
|---|---|
| Политическая природа | **максимальная** — цена и объём определяются политикой, а не рынком |
| Что произошло | основная часть потока обнулена; часть инфраструктуры повреждена или не работает |
| Остаточная экспозиция | **низкая** — терять почти нечего, эскалация мало что меняет |
| Возвратный потенциал | **низкий**: покупатель построил приёмные терминалы под сжиженный газ, подписал долгосрочные контракты с другими поставщиками, закрепил диверсификацию политически; часть трубопроводной инфраструктуры физически недоступна |
| Вывод | канал уже реализован как потеря; ни эскалация, ни мир его существенно не меняют |

Это эталонный пример того, почему нужен реестр: интуиция подсказывает «мир вернёт газовый
экспорт», а механика замещения говорит обратное.

### Нефть и нефтепродукты

| Параметр | Оценка |
|---|---|
| Политическая природа | высокая, но товар ликвиден и легко перенаправляется |
| Что произошло | география поставок переориентирована; объёмы во многом сохранены; ущерб перешёл в **дисконт и логистику** |
| Остаточная экспозиция | **средняя–высокая**: ужесточение по теневой логистике, страхованию, вторичным санкциям на покупателей может ударить по объёмам |
| Возвратный потенциал | **высокий по цене, средний по географии**: дисконт сужается быстро, но прежние рынки сбыта частично закрыты надолго |
| Вывод | главный измеритель здесь не объём, а клин (Часть 2.4) |

### Уголь

| Параметр | Оценка |
|---|---|
| Политическая природа | высокая |
| Что произошло | переориентация на восточное направление, упор в пропускную способность |
| Остаточная экспозиция | средняя: физическое ограничение логистики важнее санкционного |
| Возвратный потенциал | средний: рынок конкурентный, ниша занята другими поставщиками |
| Особенность | **узкое место не политическое, а инфраструктурное** — даже при мире вывезти больше нельзя без расширения путей |

### Металлы

| Параметр | Оценка |
|---|---|
| Политическая природа | средняя: часть позиций критична для мировой промышленности, что снижает готовность вводить полный запрет |
| Что произошло | ограничения на часть номенклатуры, переориентация потоков |
| Остаточная экспозиция | средняя: незатронутые позиции остаются под риском |
| Возвратный потенциал | средний–высокий: биржевой товар, возврат проще, чем в трубопроводных поставках |

### Удобрения и зерно

| Параметр | Оценка |
|---|---|
| Политическая природа | средняя, ограничена соображениями продовольственной безопасности |
| Что произошло | прямых запретов меньше, но логистика, страхование и расчёты усложнены |
| Остаточная экспозиция | средняя |
| Возвратный потенциал | **высокий**: спрос устойчив, замещение затруднено, продовольствие обычно выводят из-под ограничений |
| Вывод | наименее уязвимое экспортное направление |

### Импорт технологий и оборудования

| Параметр | Оценка |
|---|---|
| Политическая природа | максимальная |
| Что произошло | ограничение доступа, замещение параллельным импортом с наценкой и потерей качества |
| Остаточная экспозиция | **высокая**: перечни расширяются, правоприменение ужесточается |
| Возвратный потенциал | **низкий с гистерезисом**: даже при снятии ограничений упущенное поколение технологий не догоняется |
| Вывод | главный канал долгосрочного ущерба потенциальному ВВП |

### Авиация и транспорт

| Параметр | Оценка |
|---|---|
| Политическая природа | максимальная (воздушное пространство, лизинг, запчасти) |
| Что произошло | закрытие направлений, проблемы с обслуживанием парка |
| Остаточная экспозиция | средняя |
| Возвратный потенциал | средний: маршруты открываются относительно быстро, но парк и его обслуживание — вопрос лет |

### Финансовая инфраструктура

| Параметр | Оценка |
|---|---|
| Политическая природа | максимальная |
| Что произошло | ограничение расчётов, заморозка резервов, отключение части банков |
| Остаточная экспозиция | **высокая**: вторичные санкции на банки третьих стран — главный оставшийся рычаг |
| Возвратный потенциал | средний: техническое восстановление расчётов быстрое, но доверие и правовые риски сохраняются |

## 3.4. Как использовать реестр

**Три практических приёма:**

**1. Перед оценкой риска эскалации — свериться с остаточной экспозицией.**
Вопрос не «что могут сделать», а «что могут сделать из того, что ещё не сделано». Если
канал обнулён, эскалация по нему не несёт нового ущерба.

**2. Перед оценкой выгоды от мира — свериться с возвратным потенциалом.**
Вопрос не «что было до», а «что реально вернётся с учётом занятых ниш и построенной
конкурентами инфраструктуры».

**3. Искать асимметрию.**
Самые интересные ситуации — там, где остаточная экспозиция и возвратный потенциал сильно
расходятся:

| Ситуация | Что означает |
|---|---|
| Экспозиция низкая, возврат низкий | канал «сгорел» — не пугает и не радует |
| Экспозиция **высокая**, возврат низкий | **чистый риск** — можно только потерять |
| Экспозиция низкая, возврат **высокий** | **чистая опция** — можно только выиграть |
| Экспозиция высокая, возврат высокий | канал живой, максимальная чувствительность к сценарию |

Третья строка — то, что рынок обычно недооценивает: направления, где терять уже нечего, а
при деэскалации есть что приобрести.

# ЧАСТЬ 4. РЕАКЦИЯ ГОСУДАРСТВА И ЦБ

Это тот слой, который превращает анализ из линейного в рекурсивный. Первичный шок почти
никогда не доходит до итогового результата в чистом виде — между ними стоит реакция
политики.

## 4.1. Фискальная реакция

| Инструмент | Когда применяется | Побочный эффект |
|---|---|---|
| Рост расходов | поддержка спроса, военные нужды | проинфляционно, требует финансирования |
| Рост налогов и изъятий | закрытие дефицита | давит на инвестиции и деловую активность |
| Точечное изъятие у прибыльных секторов | быстрый источник доходов | эффект прецедента: премия за риск растёт для всех |
| Субсидии и льготное кредитование | поддержка отраслей | **ослабляет трансмиссию ДКП** |
| Заимствования | покрытие дефицита | рост доходностей → стоимость капитала для всех |
| Использование резервов | сглаживание | исчерпаемо |

**Ключевая связка:** чем больше бюджетный импульс, тем более жёсткая ДКП требуется для
той же инфляции. Это создаёт конфигурацию «мягкий бюджет + жёсткая ставка», при которой
частный сектор вытесняется дважды: и ресурсами, и стоимостью денег.

## 4.2. Монетарная реакция

**Первое, что должен определить агент — какого типа шок с точки зрения ЦБ:**

| Тип шока | Пример | Реакция ЦБ |
|---|---|---|
| **Спросовый** | бюджетный импульс | однозначное ужесточение |
| **Предложения** | разрушение мощностей, ограничение импорта | **дилемма**: ужесточение усилит спад выпуска |
| **Валютный** | отток капитала, падение экспорта | ужесточение + возможные валютные меры |
| **Финансовой стабильности** | набег на банки, паника | смягчение и предоставление ликвидности, **несмотря на инфляцию** |

Это критично: при шоке предложения стандартная логика «инфляция ↑ → ставка ↑» работает
хуже, потому что ставка не создаёт мощности и не отменяет ограничения на импорт. ЦБ
вынужден выбирать между инфляцией и выпуском.

**Военная конфигурация — конфликт политик:**

```
Фискальная политика стимулирующая (расходы растут)
Монетарная политика ограничительная (ставка высокая)

→ государственный спрос растёт, частный вытесняется
→ структура экономики смещается в сторону госсектора
→ при этом инфляция всё равно выше цели, потому что импульс большой
```

## 4.3. Административная реакция

Отдельный слой, который часто оказывается сильнее рыночных механизмов:

| Мера | Прямой эффект | Побочный |
|---|---|---|
| Ограничения на движение капитала | стабилизация курса | падение инвестиционной привлекательности |
| Обязательная продажа валютной выручки | поддержка курса | издержки для экспортёров |
| Регулирование цен | сдерживание инфляции в статистике | дефицит, теневой рынок, потери производителей |
| Экспортные ограничения | насыщение внутреннего рынка | потеря выручки, сигнал ненадёжного поставщика |
| Директивное кредитование | поддержка отраслей | искажение трансмиссии ДКП |

**Важно для интерпретации данных:** административное сдерживание цен переводит инфляцию
из наблюдаемой в скрытую (дефицит, ухудшение качества, теневой рынок). Индекс цен может
выглядеть лучше, чем реальность.

## 4.4. Как реакция меняет параметры модели

Реакция политики не просто добавляет эффект — она **деформирует механизмы** (связь с
2.14):

```
Льготное кредитование     → ставка перестаёт влиять на часть заёмщиков
Регулирование цен         → ценовой сигнал не проходит
Госзаказ                  → спрос не зависит от рыночной конъюнктуры
Валютные ограничения      → курс перестаёт быть равновесным индикатором
```

Поэтому после масштабного вмешательства традиционные индикаторы теряют часть
информативности, и агент обязан это оговаривать.

# ЧАСТЬ 5. ПЕТЛИ ОБРАТНОЙ СВЯЗИ И ВЗАИМОДЕЙСТВИЯ

## 5.1. Основные петли

Агент обязан искать не только линейные цепочки, но и замыкающиеся контуры.

### Петля 1: бюджет — инфляция — ставка

```
Военные расходы ↑ → спрос ↑ → инфляция ↑ → ставка ЦБ ↑
   → частный спрос и инвестиции ↓
   → налоговая база растёт медленнее
   → дефицит сохраняется → давление на расходы продолжается
```

### Петля 2: труд — зарплаты — инфляция

```
Мобилизация → предложение труда ↓ → зарплаты ↑ → издержки ↑ → инфляция ↑
   → ставка ↑ → но ставка НЕ создаёт рабочие руки
   → инфляция не уходит → ставка держится высокой дольше
```

Ключевая особенность: это шок предложения, против которого ставка малоэффективна.
Отсюда затяжной характер высокой ставки.

### Петля 3: курс — инфляция — ставка

```
Санкции → экспортная выручка и приток капитала ↓ → рубль ↓
   → импортные цены ↑ → инфляция ↑ → ставка ↑
   → высокая ставка поддерживает рубль → частично гасит петлю
```

### Петля 4: неопределённость — инвестиции — потенциал

```
Неопределённость ↑ → инвестиции ↓ → обновление фондов ↓
   → производительность ↓ → потенциальный ВВП ↓
   → тот же спрос даёт больше инфляции
   → ставка выше → инвестиции ещё ниже
```

Самая опасная петля: она превращает временный шок в постоянное снижение траектории роста.

### Петля 5: бюджет — курс

```
Экспортные цены ↑ → доходы бюджета ↑ → расходы ↑
   → спрос на импорт ↑ → давление на курс ↓
   → рублёвая выручка экспортёров ↑ → доходы бюджета ↑ ...
```

### Петля 6: сырьё — мировой рост

```
Цена нефти ↑ → мировая инфляция ↑ → мировые ставки ↑
   → мировой рост ↓ → спрос на сырьё ↓ → цена нефти ↓
```

Самокорректирующаяся петля: она ограничивает выгоду от ценового шока на горизонте
нескольких кварталов.

## 5.2. Взаимодействия каналов — эффект умножения

Каналы не просто складываются. Некоторые комбинации дают эффект больше суммы:

| Комбинация | Почему усиливает |
|---|---|
| **Бюджетный импульс × дефицит труда** | спрос растёт там, где нет свободных ресурсов → почти весь импульс уходит в цены, а не в выпуск |
| **Санкции × слабый рубль** | импорт дорожает дважды: от курса и от санкционной наценки |
| **Санкции × высокая импортозависимость** | нет замены — эффект переносится в производство целиком |
| **Ограничение технологий × длинный инвестцикл** | невозможно ни купить, ни отложить — проекты просто отменяются |
| **Монополизация × административные цены** | трансмиссия ДКП ломается с двух сторон |
| **Неопределённость × высокая ставка** | инвестиции падают и от риска, и от стоимости денег |

**Практическое правило:** если в анализе два и более фактора из этой таблицы совпали,
эффект надо оценивать выше, чем сумму отдельных оценок, и явно это отмечать.

# ЧАСТЬ 6. ГОРИЗОНТЫ, ЛАГИ, ОБРАТИМОСТЬ

## 6.1. Таблица лагов

| Канал | Когда проявляется |
|---|---|
| Финансовые рынки, премия за риск | практически мгновенно |
| Валютный курс | дни |
| Мировые цены на сырьё | дни–недели |
| Ожидания и поведение | недели |
| Цены импортных товаров | недели–месяцы |
| Государственные расходы | месяцы |
| Рынок труда, зарплаты | месяцы–квартал |
| Инфляция (полный эффект) | 2–4 квартала |
| Инвестиции | кварталы |
| Кредитное качество | 2–4 квартала |
| Производительность | годы |
| Технологическое отставание | годы |
| Демография и человеческий капитал | годы–десятилетия |
| Потенциальный ВВП | годы |

**Следствие:** нельзя сравнивать эффект, проявившийся через неделю, с эффектом, который
раскроется через пять лет. Каждый вывод должен быть привязан к горизонту.

## 6.2. Классификация обратимости — ключ к сценариям мира

| Класс | Что означает | Примеры каналов |
|---|---|---|
| **Быстро обратимый** | возвращается за недели–месяцы после снятия причины | премия за риск, фрахтовые ставки, дисконт к цене, расчётная инфраструктура, курс |
| **Медленно обратимый** | возвращается за 1–3 года | объёмы поставок на сохранившиеся рынки, инвестиционная активность, часть логистики |
| **С гистерезисом** | возвращается частично и не полностью | доля рынка, доверие контрагентов, квалификация кадров, инвестиционный климат |
| **Необратимый** | не возвращается вовсе | утраченное технологическое поколение, потерянный человеческий капитал, разрушенные и не восстановленные активы, изменённая структура собственности |

**Главное правило для сценария мира:**

```
Сценарий деэскалации = сумма ТОЛЬКО обратимых каналов
                     + частичный возврат по каналам с гистерезисом
                     + ноль по необратимым
```

Прогноз «при мире экономика вернётся к довоенной траектории» неверен по построению: часть
каналов необратима. Правильная формулировка — какие именно каналы отыграют, на сколько и
за какой срок.

## 6.3. Шок уровня против шока тренда

Самое важное различение всей методички.

| | Шок уровня | Шок тренда |
|---|---|---|
| Что меняется | текущее значение переменной | долгосрочный темп роста |
| Пример | временный всплеск госрасходов | технологическая изоляция + падение инвестиций |
| Последствие | экономика возвращается на прежнюю траекторию | траектория смещается вниз навсегда |
| Как распознать | эффект затухает сам | эффект накапливается |

```
Шок уровня:   Y ↓, затем возврат к прежней траектории
Шок тренда:   g* ↓ — снижается САМ ТЕМП роста
```

Второй случай на порядок серьёзнее, но проявляется медленно и потому недооценивается в
моменте. Каналы, ведущие к шоку тренда: технологические ограничения, падение инвестиций,
потеря человеческого капитала, снижение конкуренции.

## 6.4. Фактический ВВП против потенциального и благосостояния

Три разные вещи, которые постоянно смешивают:

```
Фактический ВВП может РАСТИ         (военный госзаказ считается в ВВП)
Потенциальный ВВП при этом ПАДАТЬ   (труд, капитал, технологии сокращаются)
Благосостояние ПАДАТЬ ещё сильнее   (произведённое не идёт на потребление)
```

**Правило для агента:** при росте ВВП за счёт государственного и военного спроса
обязательно отмечать, что это перераспределение ресурсов, а не рост производственного
потенциала. Иначе вывод «экономика растёт» будет формально верным и содержательно
обманчивым.

# ЧАСТЬ 7. ЭСКАЛАЦИЯ И ДЕЭСКАЛАЦИЯ

## 7.1. Порядок активации каналов при эскалации

При росте интенсивности каналы включаются не одновременно, а последовательно.

| Уровень | Что происходит | Доминирующий канал | Лаг |
|---|---|---|---|
| 1 | рост боевых расходов | фискальный: спрос ↑, инфляция ↑ | месяцы |
| 2 | рост потребности в людях | труд: предложение ↓, зарплаты ↑ | месяцы |
| 3 | наращивание военного производства | вытеснение гражданского сектора | кварталы |
| 4 | усиление ограничений | издержки, дисконт, технологии | кварталы |
| 5 | удары по инфраструктуре | предложение ↓, издержки ↑ | немедленно и далее |
| 6 | рост неопределённости | инвестиции ↓, сбережения ↑ | кварталы |
| 7 | рост финансового риска | стоимость капитала ↑ | немедленно |
| 8 | вовлечение третьих стран | глобальные каналы, вторичные меры | месяцы |

**Порог качественного перехода.** После определённого уровня конфликт перестаёт быть
локальным шоком и становится международным — тогда к прямым каналам добавляются
глобальные (Часть 8), и знак совокупного эффекта может измениться.

## 7.2. Деэскалация: что развязывается и в каком порядке

**Главное правило:** прекращение боевых действий — это одно событие, а не пакет. Надо
анализировать раздельно:

| Событие | Обычная скорость | От чего зависит |
|---|---|---|
| Прекращение огня | момент | политическое решение |
| Снижение военных расходов | **медленно** | контракты, занятость, политэкономия (храповик) |
| Демобилизация | месяцы–годы | решение о численности |
| Снижение премии за риск | **быстро** | восприятие рынка |
| Снятие ограничений | **медленно и частично** | требует юридических процедур и согласия многих сторон |
| Возврат расчётной инфраструктуры | быстро после снятия | техническая задача |
| Возврат компаний | **годы** | корпоративные решения, репутационные риски |
| Возврат капитала | годы | доверие, права собственности |
| Восстановление технологического доступа | **годы или никогда** | конкуренты ушли вперёд |
| Возврат долей на рынках | частично или никогда | ниши заняты (Часть 3.2) |

## 7.3. Почему мир ≠ автоматическое улучшение

Пять причин, которые агент обязан проверить:

**1. Расходы не падают синхронно с боевыми действиями.** Остаются восстановительные
расходы, повышенная численность, оборонный заказ, обязательства перед участниками. Это
фискальный храповик.

**2. Ограничения могут сохраниться.** Снятие требует политического процесса, часто
согласия многих сторон, и обычно происходит частями. Возможна конфигурация: боевые
действия прекратились, ограничения остались — тогда исчезает бюджетный импульс, а
технологические и торговые ограничения продолжают давить. **Это может быть хуже для
экономики в моменте**, чем предыдущее состояние.

**3. Ниши заняты.** Возвратный потенциал ниже базы (Часть 3.2).

**4. Часть ущерба необратима.** Технологии, кадры, разрушенные активы, изменённая
структура собственности.

**5. Возвращается конкуренция.** При нормализации иностранные компании возвращаются на
внутренний рынок, а на внешних рынках исчезает дисконтная ниша. Для отдельных отраслей,
выигравших от ухода конкурентов, мир — **негативное событие**.

**Формат вывода по сценарию мира:**

```
Не «экономика восстановится», а:

Быстро отыграют:      премия за риск, дисконт, расчёты, курс
Медленно отыграют:    инвестиции, часть логистики, отдельные рынки
Частично отыграют:    доли рынка, доверие, кадры
Не отыграют:          технологическое поколение, утраченный человеческий капитал
Ухудшатся:            позиции отраслей, выигравших от изоляции
```

# ЧАСТЬ 8. ВНЕШНИЕ КОНФЛИКТЫ (РОССИЯ НЕ УЧАСТНИК)

## 8.1. Другая логика анализа

При внешнем конфликте **нельзя** начинать с «конфликт → российский бюджет». Цепочка иная:

```
Внешний конфликт
   → изменение ГЛОБАЛЬНОЙ переменной
   → приход этой переменной в Россию
   → российская макропеременная
```

**Первый вопрос:** какие глобальные переменные меняет конфликт?

| Глобальная переменная | Как приходит в Россию |
|---|---|
| Цены на нефть, газ, металлы, продовольствие | экспортная выручка, бюджет, курс |
| Мировой рост | спрос на сырьевой экспорт |
| Мировая инфляция | цены импорта, мировые ставки |
| Мировые ставки | внешние финансовые условия, стоимость капитала |
| Стоимость перевозок и страхования | издержки импорта и экспорта |
| Доступность технологий | производительность |
| Санкционные режимы | вторичные ограничения |
| Структура цепочек поставок | доступность компонентов |

## 8.2. Конфликт в нефтегазовом регионе

**Прямой эффект:** близок к нулю. **Косвенные — сильные и разнонаправленные:**

```
+ Риск перебоя поставок → мировая цена нефти ↑ → экспортная выручка ↑
+ Условия торговли улучшаются → бюджет ↑
− Мировая инфляция ↑ → мировые ставки ↑ → глобальный рост ↓ → спрос на сырьё ↓
− Нарушение морских маршрутов → фрахт и страхование ↑ → импорт дорожает
± Курс: приток валюты укрепляет рубль, что бьёт по рублёвой выручке экспортёров
```

**Итог неоднозначен.** Первая волна — позитив через цены. Вторая волна (2–4 квартала) —
негатив через глобальное замедление и удорожание импорта. Агент обязан посчитать нетто по
горизонтам, а не остановиться на «нефть подорожала, значит хорошо».

**Отдельная проверка:** способна ли Россия физически реализовать выгоду от роста цены —
есть ли свободные мощности, логистика, покупатели. Рост мировой цены при невозможности
нарастить поставки даёт меньший эффект, чем кажется.

## 8.3. Конфликт в Азиатско-Тихоокеанском регионе

Здесь структура принципиально иная: под ударом не сырьё, а **производственные цепочки**.

| Канал | Механизм | Эффект для России |
|---|---|---|
| Полупроводники и электроника | нарушение производства → дефицит компонентов | удорожание и дефицит импорта, удар по промышленности |
| Морская торговля | нарушение маршрутов → фрахт ↑ | удорожание импорта и экспортной логистики |
| Мировой рост | падение производства в регионе → мировой ВВП ↓ | спрос на сырьевой экспорт ↓ |
| Торговля ключевого партнёра | переориентация его потоков | изменение условий торговли с ним |
| Сырьевые рынки | разнонаправленно | зависит от товара |

**Ключевое отличие от нефтяного сценария:** там первая волна позитивна (цены), здесь
первая волна скорее негативна (компоненты, логистика, спрос). Плюс возникает риск через
концентрацию: если основной покупатель российского экспорта вовлечён в конфликт, под
ударом оказывается сам канал сбыта.

## 8.4. Конфликт, где Россия — объект вторичных мер

Отдельная конфигурация: военного шока нет, но есть санкционная передача.

```
Внешний конфликт → вовлечён партнёр России → вторичные меры против России
```

Проверять: расчёты, банки-корреспонденты, экспорт, импорт, технологии, страхование,
судоходство, платёжные системы, валюта расчёта.

Этот канал может бить сильнее, чем сам военный конфликт, потому что действует через
поведение нейтральных контрагентов (см. 2.3).

## 8.5. Конфигурация, где Россия выигрывает

Обязательный к проверке случай — иначе анализ будет систематически смещён в негатив.

```
Глобальный дефицит товара, который Россия экспортирует
   → мировая цена ↑
   → условия торговли ↑
   → экспортная выручка, бюджет ↑
```

**Правило:** никогда не применять презумпцию «любой конфликт вреден для России». Надо
считать нетто по каналам:

| Плюсы | Минусы |
|---|---|
| экспортные цены ↑ | мировая торговля ↓ |
| доходы бюджета ↑ | импортная инфляция ↑ |
| условия торговли ↑ | финансовый риск ↑ |
| спрос на альтернативные поставки ↑ | глобальный рост ↓ |

# ЧАСТЬ 9. ВЫХОДНЫЕ ПЕРЕМЕННЫЕ И ФОРМАТ ВЫВОДА

## 9.1. Набор переменных на выходе

Чтобы анализ не превращался в эссе, итог фиксируется в конечном наборе:

| Блок | Переменные |
|---|---|
| **Реальный сектор** | ВВП, потенциальный ВВП, производительность, разрыв выпуска |
| **Инфляция** | общая, базовая, цены производителей, инфляционные ожидания |
| **Рынок труда** | занятость, безработица, вакансии, зарплаты, производительность труда |
| **Бюджет** | баланс, первичный баланс, долг, обслуживание долга, расходы, налоговая нагрузка |
| **Денежный сектор** | ключевая ставка, кредитование, денежная масса |
| **Внешний сектор** | экспорт, импорт, текущий счёт, условия торговли, резервы |
| **Валютный рынок** | курс, валютная ликвидность, потоки капитала |
| **Инвестиции** | частные, государственные, стоимость капитала |
| **Структурные** | производительность, технологический уровень, концентрация рынков, человеческий капитал, структура торговли, зависимость от отдельных поставщиков |

Последний блок особенно важен: эти показатели могут не двигать текущий ВВП, но определяют
будущий.

## 9.2. Обязательная структура вывода

```
1. СОБЫТИЕ            что именно произошло (факт, без домыслов)
2. КОНФИГУРАЦИЯ       роль России, изменения по вектору интенсивности
3. ПЕРВИЧНЫЕ ШОКИ     что изменилось непосредственно
4. КАНАЛЫ             какие задействованы, с направлением, силой, лагом
5. РЕАКЦИЯ ПОЛИТИКИ   что сделают бюджет и ЦБ
6. ВТОРИЧНЫЕ ЭФФЕКТЫ  что следует из реакции
7. ПО ГОРИЗОНТАМ      0–3 мес / 3–12 мес / 1–3 года / 3–10 лет
8. КОНТРФАКТ          что было бы без события
9. НЕТТО-ЭФФЕКТ       по каждой ключевой переменной
10. ОБРАТИМОСТЬ       что отыграется при развороте, что нет
11. ЧТО ОТСЛЕЖИВАТЬ   наблюдаемые триггеры смены сценария
```

## 9.3. Правила формулирования

**Обязательно:**

- разметка каждого эффекта: прямой/косвенный, порядок, лаг, обратимость;
- класс масштаба вместо выдуманной точности (малый / умеренный / значимый / режимный);
- разделение фактического и потенциального ВВП;
- явное указание, где заканчивается наблюдаемое и начинается суждение.

**Запрещено:**

- задавать знак заранее («конфликт вреден для экономики»);
- давать точные числа там, где их нет («инфляция +1,4 п.п.»);
- сравнивать эффекты разных горизонтов между собой;
- останавливаться на первом порядке эффектов;
- предсказывать сами политические события (можно оценивать последствия «если», нельзя
  утверждать, что произойдёт);
- уходить в политические и моральные оценки — анализ экономический.

# ЧАСТЬ 10. ДАННЫЕ И ИХ ДЕГРАДАЦИЯ

Отдельная часть, потому что в геополитическом контексте сама возможность измерения
ухудшается — и это методологическая проблема, а не мелкая деталь.

## 10.1. Что происходит с данными

| Проблема | Проявление | Что делать |
|---|---|---|
| Закрытие публикации | таможенная статистика, отдельные ряды | зеркальная статистика стран-партнёров |
| Изменение методологии | пересмотр состава показателей | отмечать разрыв ряда, не сравнивать напрямую |
| Задержка публикации | данные выходят позже | опираться на опережающие и оперативные индикаторы |
| Искажение через регулирование | административные цены скрывают инфляцию | смотреть дефицит, качество, теневой рынок |
| Неполнота охвата | теневые схемы не попадают в статистику | оценивать по косвенным признакам |

## 10.2. Зеркальная статистика — основной обходной путь

```
Если своя таможенная статистика закрыта:
   взять данные СТРАН-ПАРТНЁРОВ о торговле с Россией
   → сумма их импорта из России ≈ российский экспорт
```

Ограничения метода: не покрывает страны, которые сами не публикуют; расхождения из-за
реэкспорта и разной методологии; лаг публикации. Но это лучше, чем отсутствие данных.

## 10.3. Прокси-индикаторы

| Что нужно измерить | Чем заменить при отсутствии прямых данных |
|---|---|
| Объёмы экспорта нефти | данные морского трекинга, статистика портов-получателей |
| Реальная инфляция | цены отдельных корзин, данные ритейлеров, опросы |
| Промышленная активность | потребление электроэнергии, погрузка на железной дороге |
| Состояние потребителя | оборот розницы, кредитная активность, автопродажи |
| Занятость и напряжённость рынка труда | вакансии и резюме на рекрутинговых площадках |
| Логистические издержки | фрахтовые индексы, ставки аренды подвижного состава |

## 10.4. Обязательная оговорка в выводе

Если ключевые данные недоступны или заменены прокси, агент указывает это явно, а не
маскирует уверенным тоном. Формулировка вида «прямые данные по этому направлению не
публикуются, оценка построена на зеркальной статистике партнёров» повышает доверие, а не
снижает его.

# ЧАСТЬ 11. ЧЕК-ЛИСТ ОШИБОК

**Методологические:**

- [ ] Не построен контрфакт: эффект измерен «до и после», а не относительно сценария без события.
- [ ] Знак эффекта задан заранее, а не получен из анализа каналов.
- [ ] Анализ остановлен на первом порядке эффектов.
- [ ] Не указан горизонт вывода; эффекты разных горизонтов сравниваются между собой.
- [ ] Не определён исходный макрорежим (один шок в перегреве и в спаде даёт разное).
- [ ] Не отмечена обратимость каналов — сценарий мира построен как возврат к базе.
- [ ] Применены довоенные эластичности к военному режиму (см. 2.14).

**По каналам:**

- [ ] Фискальный импульс учтён без проверки, доходит ли он до публичного сектора.
- [ ] Рост госрасходов записан в рост экономики без учёта вытеснения гражданского сектора.
- [ ] Потери труда посчитаны в единицах, без учёта возрастной и квалификационной структуры.
- [ ] Санкция принята за автоматическую потерю производства без оценки замещения и наценки.
- [ ] Учтён формальный запрет, но не поведение контрагентов (сверхсоблюдение).
- [ ] Эффект оценён по объёму экспорта, а не по клину между мировой и полученной ценой.
- [ ] Не учтено, что выручка может не дойти (расчёты, неконвертируемые остатки).
- [ ] Повреждение инфраструктуры оценено по доле мощности без учёта узких мест и резервов.
- [ ] Не учтено влияние монополизации на эффективность денежной политики.
- [ ] Инвестиционный спад объяснён только ставкой, без ценности ожидания при неопределённости.
- [ ] Смешаны фактический и потенциальный ВВП; рост военного производства выдан за рост экономики.

**По секторальной экспозиции:**

- [ ] Не проверена остаточная экспозиция — риск приписан каналу, который уже обнулён.
- [ ] Возвратный потенциал приравнен к довоенной базе без учёта занятых конкурентами ниш.
- [ ] Не учтено, что для отдельных отраслей деэскалация — негативное событие (возврат конкуренции).

**По внешним конфликтам:**

- [ ] Анализ начат с российского бюджета вместо глобальных переменных.
- [ ] Учтена только первая волна (цены), пропущена вторая (глобальное замедление).
- [ ] Не проверена физическая способность реализовать выгоду от роста цен.
- [ ] Применена презумпция «любой конфликт вреден для России» без расчёта нетто.

**По данным и подаче:**

- [ ] Использованы данные, публикация которых прекращена, без оговорки.
- [ ] Выдуманы точные числа там, где есть только направление.
- [ ] Гипотетический сценарий подан как прогноз события.
- [ ] Экономический анализ подменён политической оценкой.

## Приложение. Краткий алгоритм анализа

```
1.  Зафиксировать событие (факт, не интерпретацию)
2.  Определить роль России (5 конфигураций)
3.  Оценить изменения по вектору интенсивности (K,M,G,S,T,F,R,C)

6.  Прогнать по 14 каналам: направление, сила, лаг, обратимость
7.  Свериться с реестром экспозиции: что уже потеряно, что осталось
8.  Определить реакцию бюджета и ЦБ
9.  Найти петли обратной связи и взаимодействия каналов
10. Разложить по горизонтам (0–3 мес / 3–12 мес / 1–3 года / 3–10 лет)
11. Построить контрфакт
12. Получить нетто-эффект по каждой переменной
13. Отметить обратимость: что отыграется при развороте
14. Назвать наблюдаемые триггеры смены сценария
```
