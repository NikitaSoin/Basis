Все крупные разделы платформы, у которых есть левый навигационный сайдбар, используют
ОДИН И ТОТ ЖЕ визуальный паттерн — «theme-invariant dark rail» (тёмный ВСЕГДА, независимо
от того, светлая или тёмная тема сайта выбрана пользователем):

- `.obs-sidebar` (Обозреватель, `styles/observer-v2.css`)
- `.mkt-sidebar` (Рынок, `styles/market-sidebar.css`)
- `.pf-sidebar` (Портфель, `styles/portfolio-v2.css`)
- `.scmp-sidebar` (Скринер/Сравнение, `styles/screener-compare.css`)
- `.asst-side` (Ассистент, `styles/assistant.css`) — добавлен 2026-07-26 (см.
  [[assistant-sidebar-redesign]])

Общие черты (буквально одинаковые значения, не «вдохновение»):
- Палитра — 7 локальных CSS-переменных, СКОУПЛЕННЫХ на класс самого сайдбара (не в
  общих `--bg-*`/`--text-*`, иначе подхватили бы тему сайта): `--{prefix}-deep:#12131A`,
  `-deep-2:#1B1C26`, `-deep-3:#24252F`, `-deep-line:rgba(255,255,255,0.10)`,
  `-deep-ink:#EDEBE3`, `-deep-ink2:#9B9AA8`, `-deep-ink3:#6C6B78`.
- Ширина докованного рельса — 260px (Ассистент — 280px, у него другая композиция:
  сайдбар внутри бордеренной карточки чата, не edge-to-edge на всю высоту вьюпорта).
- Пункт списка/нав-айтем: default color ink2, transparent bg; hover → bg deep-2 + color
  ink; active → сплошная заливка `var(--accent)` (медь) + `box-shadow: 0 3px 12px -3px
  rgba(201,122,74,0.40)` (это и есть --bs-copper в rgba, не новая придумка).
- Подпись-заголовок группы (eyebrow/zone-label) — mono, 10px, uppercase, letter-spacing
  ~0.10em, цвет ink3.
- Мобильный ≤760px — `.msd-drawer`/`useMobileSidebarDrawer()`
  (`design/MobileSidebarDrawer.jsx`, `styles/mobile-sidebar-drawer.css`): рельс получает
  доп. класс `msd-drawer`(`+msd-drawer--open`), становится transform-based overlay,
  z-index 110 !important (выше mnav-tabbar 100).

**Why:** это устоявшийся, уже прошедший ревью визуальный язык навигации сайта («второй
рейл всегда тёмный, контент рядом — светлый/по теме»). Owner (2026-07-26), про Ассистент:
«левую часть — в виде сайдбара такого же, как в других блоках (рынок/обозреватель/
портфель)» — прямой запрос копировать ИМЕННО эту палитру 1:1, не изобретать новую тёмную
гамму.

**How to apply:** при любом новом/переделываемом сайдбаре на платформе — бери эти же 7
переменных 1:1 (скоупленные под свой префикс), ту же структуру hover/active, тот же
mobile-drawer рецепт. НЕ выдумывай новую тёмную палитру, НЕ используй `--bg-elevated`/
`--text-*` для рельса (они меняются с темой сайта, а рельс — нет, это осознанный design
spec, не баг). См. также [[accent-on-accent-contrast-caveat]] про активный пункт (медная
заливка + текст) — там нюанс с контрастом.
