# Методичка: связь макроэкономики с бизнесом по секторам

**Назначение.** Справочник для агента и для человека: какие показатели описывают бизнес
каждого сектора, что они означают, и как конкретно макросреда через них проходит до
выручки, маржи и денежного потока.

**Как устроен документ:**

| Часть | Что внутри |
|---|---|
| 0 | Как пользоваться: универсальная цепочка, типы индикаторов, как читать связки |
| 1 | Универсальный каркас: 10 слоёв анализа любого сектора |
| 2 | Сквозные макродрайверы и их количественные якоря |
| 3 | 20 секторов по единому шаблону |
| 4 | Сводная таблица эластичностей и лагов |
| 5 | Источники данных: откуда что тянуть |
| 6 | Фискальный блок: налоги, изъятия, госрасходы |
| 7 | Чек-лист ошибок |

**Важная оговорка про числа.** Все числовые ориентиры в документе — **индикативные
диапазоны для калибровки**, а не нормативы. Конкретные значения всегда проверяются по
отчётности компании. Эластичности, взятые из зарубежных исследований, требуют адаптации
к российским данным — это помечено в тексте.

# ЧАСТЬ 0. КАК ПОЛЬЗОВАТЬСЯ

## 0.1. Универсальная цепочка трансмиссии

Любая связь «макро → акция» проходит по одной и той же лестнице. Анализ обязан идти по
ступеням, а не прыгать с первой на последнюю.

```
МАКРОЭКОНОМИКА
      ↓
ФИНАНСОВЫЕ УСЛОВИЯ        (ставки, курс, доступность кредита)
      ↓
ОТРАСЛЕВОЙ ДРАЙВЕР        (ипотечная ставка, цена нефти, реальные доходы)
      ↓
ОПЕРАЦИОННАЯ МЕТРИКА      (продажи м², добыча, LFL, NIM)
      ↓
UNIT ECONOMICS            (маржа на единицу, спред)
      ↓
P&L                       (выручка → EBITDA → прибыль)
      ↓
CASH FLOW                 (операционный поток, CAPEX, FCF)
      ↓
БАЛАНС                    (долг, оборотный капитал)
      ↓
ОЦЕНКА                    (ставка дисконтирования, мультипликаторы)
```

**Правило:** называя эффект, указывай, на какой ступени он возникает. «Высокая ставка
плохо для девелопера» — бесполезно. «Высокая ставка → ипотека дороже → продажи м² падают
→ выручка и наполнение эскроу падают → ставка проектного финансирования растёт →
процентные расходы съедают прибыль» — это анализ.

## 0.2. Три типа индикаторов — обязательная разметка

Это одно из самых важных различий во всей методичке.

| Тип | Что делает | Пример для банка |
|---|---|---|
| **Leading** (опережающий) | предсказывает будущее изменение | кредитный импульс, выдачи, Stage 2, PMI |
| **Coincident** (совпадающий) | описывает текущее состояние | рост портфеля, NIM, депозиты |
| **Lagging** (запаздывающий) | подтверждает то, что уже случилось | NPL, резервы, ROE |

**Почему это критично.** Если NPL низкий, но кредитный импульс падает, PMI ниже 50,
безработица растёт и прибыли компаний сжимаются — нельзя говорить «качество кредита
хорошее». NPL просто ещё не успел ухудшиться: он запаздывает на 2–4 квартала.

В карточке компании опережающие метрики должны стоять **выше** запаздывающих.

## 0.3. Как читать связку «макро → метрика»

По каждой связке фиксируем пять вещей:

| Параметр | Что означает |
|---|---|
| **Механизм** | через что конкретно передаётся эффект |
| **Направление** | знак: рост фактора → рост или падение метрики |
| **Вид зависимости** | линейная / нелинейная / пороговая / асимметричная / с насыщением |
| **Лаг** | через сколько кварталов проявится |
| **Сила** | эластичность или коэффициент чувствительности, если он оценён |

**Про вид зависимости.** Самые опасные ошибки возникают там, где связь нелинейна:

- **Пороговая** — работает как выключатель. Ипотечная ставка выше ~18% почти обнуляет
  рыночный спрос; между 8% и 12% разница плавная, между 16% и 20% — обрыв.
- **Асимметричная** — знак «туда» и «обратно» разной силы. Ослабление рубля переходит в
  цены быстрее и полнее, чем укрепление.
- **С разворотом во времени** — краткосрочный эффект противоположен долгосрочному. Рост
  ставки сначала расширяет маржу банка, потом сжимает её.

# ЧАСТЬ 1. УНИВЕРСАЛЬНЫЙ КАРКАС СЕКТОРА

У любого сектора анализ строится по десяти слоям. Меняется наполнение, не структура.

| № | Слой | Вопрос, на который отвечает | Пример (девелопер) |
|---|---|---|---|
| 1 | **Операционные KPI** | что физически делает бизнес | продажи м², запуски |
| 2 | **Unit economics** | сколько зарабатывает на единице | маржа проекта на м² |
| 3 | **Спред цена−издержки** | из чего складывается маржа | цена м² − себестоимость м² |
| 4 | **Объём** | сколько единиц продаёт | контрактация, sales velocity |
| 5 | **Маржа** | какая доля выручки остаётся | EBITDA margin |
| 6 | **CAPEX** | сколько нужно вкладывать | покупка земли, стройка |
| 7 | **Оборотный капитал** | сколько денег заморожено | незавершённое строительство |
| 8 | **Долговая нагрузка** | насколько зависим от кредита | долг без эскроу / EBITDA |
| 9 | **Денежный поток** | сколько остаётся живых денег | раскрытие эскроу, FCF |
| 10 | **Макрочувствительность** | какие внешние факторы решают | ипотечная ставка |

**Как применять:** прежде чем говорить о влиянии макро, определи, на какой слой оно
приходит первым. У девелопера ставка бьёт в слой 1 (спрос) и слой 8 (стоимость долга)
одновременно — поэтому эффект двойной. У IT-компании ставка почти не трогает слои 1–7,
но сильно бьёт в оценку. Это разные истории, и путать их нельзя.

# ЧАСТЬ 2. СКВОЗНЫЕ МАКРОДРАЙВЕРЫ

Шесть факторов, которые задевают почти все секторы. Здесь — общий механизм и
количественные якоря; отраслевая специфика в Части 3.

## 2.1. Ключевая ставка

**Что это.** Ставка, по которой ЦБ кредитует банки. Задаёт стоимость денег в экономике.

**Как доходит до бизнеса — четыре разных канала:**

```
1. СПРОС НА ПРОДУКТ
   ставка ↑ → кредит для покупателя дороже → спрос на кредитные товары ↓
   (жильё, авто, техника, мебель)

2. ПРОЦЕНТНЫЕ РАСХОДЫ
   ставка ↑ → обслуживание долга дороже → прибыль ↓
   (бьёт по компаниям с плавающим долгом и близким рефинансированием)

3. ОЦЕНКА
   ставка ↑ → доходность ОФЗ ↑ → ставка дисконтирования ↑ → оценка ↓
   (сильнее по «длинным» растущим компаниям)

4. ПРОЦЕНТНЫЙ ДОХОД (обратный знак!)
   ставка ↑ → доход на денежную подушку ↑ → прибыль ↑
   (компании-«копилки», биржа, страховщики, генераторы с кэшем)
```

**Ключевой момент:** знак эффекта зависит от баланса компании, а не от сектора. У одной
компании с чистым долгом ставка вычитает из прибыли, у соседней с чистым кэшем —
прибавляет.

**Лаг.** На оценку — мгновенно. На процентные расходы по плавающему долгу — 1 квартал.
На спрос — 2–4 квартала. На кредитное качество — 2–4 квартала.

## 2.2. Курс рубля

**Главная формула для экспортёра:**

```
Рублёвая выручка = Мировая цена × Курс
```

Смотреть только на мировую цену — грубая ошибка. Падение цены на 10% при ослаблении
рубля на 15% даёт **рост** рублёвой выручки.

**Типы компаний по валютной экспозиции:**

| Тип | Что происходит при ослаблении рубля | Примеры секторов |
|---|---|---|
| Экспортёр с рублёвыми издержками | выигрывает вдвойне | нефть, металлы, золото, удобрения |
| Импортёр сырья/товара | проигрывает | электроника, фарма, авиа (запчасти) |
| С валютным долгом | разовый убыток от переоценки | отдельные эмитенты |
| Внутренний с рублёвыми потоками | почти нейтрален | телеком, банки, ритейл |

**Перенос курса в цены (pass-through), РФ.** Долгосрочный коэффициент ≈ 0,1–0,16:
ослабление рубля на 10% даёт ~0,88 п.п. к инфляции в моменте и лишь ~0,16 п.п. в
долгосроке. **Асимметрия:** при ослаблении перенос выше, чем при укреплении. Сила
переноса выше в режиме высокой инфляции и незаякоренных ожиданий.

## 2.3. Инфляция

**Три разреза, которые нельзя путать:**

| Показатель | Что показывает | Зачем нужен |
|---|---|---|
| Headline (общая) | все цены | влияет на индексации, зарплаты |
| Core (базовая) | без волатильных компонент | определяет решения ЦБ по ставке |
| PPI (цены производителей) | издержки бизнеса | опережает потребительские цены |

**Эффект на компанию зависит от ценовой силы:**

```
Есть pricing power  → издержки переносятся в цену → маржа держится
Нет pricing power   → издержки съедают маржу
```

Прокси ценовой силы — стабильность валовой маржи в прошлые инфляционные периоды.

**Ловушка номинального роста.** Выручка +12% при инфляции 10% — это реальный рост ~2%.
Если при этом объёмы упали, качество роста плохое. Всегда очищай от инфляции.

## 2.4. Реальные располагаемые доходы

Главный драйвер всего потребительского блока. Различай эластичность по доходу:

| Эластичность | Тип товара | Что происходит в спад |
|---|---|---|
| < 1 (низкая) | продукты, ЖКХ, связь, лекарства | спрос почти не падает, но идёт trade-down |
| ≈ 1 | одежда, бытовые услуги | падает пропорционально доходам |
| > 1 (высокая) | электроника, мебель, авто, авиабилеты, ремонт | падает глубже доходов, восстанавливается быстрее |

## 2.5. ВВП и инвестиции в основной капитал

**Для потребительских секторов** якорь — доходы и потребление (C).
**Для промышленных** якорь — инвестиции в основной капитал (I), а не ВВП в целом.

Ключевой пример: более 90% потребления стали в России определяется инвестициями в
основной капитал. Поэтому металлург — это ставка на инвестиционный цикл, а не на «цену
стали».

## 2.6. Кредитный импульс

**Формула:**

```
Кредитный рост    = ΔКредит / Кредит          (насколько быстро растёт)
Кредитный импульс = Δ(Кредитного роста)       (ускоряется или тормозит)
```

**Почему важен.** Это один из немногих по-настоящему **опережающих** индикаторов:
разворачивается раньше ВВП, ориентир опережения — 9–12 месяцев.

**Пример.** Портфель растёт: +20% → +18% → +12% → +5%. Кредит всё ещё растёт, но импульс
резко отрицательный. Вывод: через 2–3 квартала ждём охлаждения спроса и инвестиций, а
ещё через 2–4 квартала — ухудшения кредитного качества.

## 3.1. БАНКИ

**Что определяет бизнес.** Банк зарабатывает на разнице ставок (процентная маржа) и
теряет на плохих кредитах (стоимость риска). Всё остальное — производные от этих двух.

### Метрики

| Метрика | Формула | Что измеряет | Ориентир (РФ) | Тип |
|---|---|---|---|---|
| **NIM** (чистая процентная маржа) | ЧПД / средние процентные активы | сколько зарабатывает на посредничестве | 4,5–6% | coincident |
| **ЧПД / NII** | процентные доходы − процентные расходы | абсолютный процентный заработок | — | coincident |
| **Spread** | ставка по активам − ставка по пассивам | «ножницы» ставок | — | coincident |
| **Deposit beta** | Δставки депозитов / Δключевой ставки | как быстро дорожает фондирование | 0,4–0,8 | leading для маржи |
| **CASA** | текущие+накопительные счета / все депозиты | доля дешёвых денег | выше = лучше | coincident |
| **Стоимость фондирования** | процентные расходы / средние обязательства | во сколько обходятся деньги | — | coincident |
| **Cost of Risk (CoR)** | резервы за период / средний портфель | плата за кредитный риск | 1,0–1,5% норма, 2,5–4% кризис | lagging |
| **NPL** | кредиты с просрочкой 90+ / портфель | доля уже плохих кредитов | — | lagging |
| **Stage 2 / Stage 3** | по МСФО 9 | Stage 2 = рост риска, ещё не дефолт | — | Stage 2 — leading к Stage 3 |
| **Покрытие резервами** | резервы / NPL | запас на потери | >100% комфортно | coincident |
| **Н1.0 / CET1** | капитал / активы, взвешенные по риску | способность поглотить убытки | минимум 8% + надбавки | coincident |
| **LCR / NSFR** | ликвидные активы / оттоки | устойчивость к набегу | минимум 100% | coincident |
| **LDR** | кредиты / депозиты | зависимость от рыночного фондирования | — | coincident |
| **Рост портфеля** | Δкредиты | динамика бизнеса | — | coincident |
| **Выдачи, approval rate** | новые кредиты, % одобрений | будущий портфель | — | **leading** |
| **Cost / Income (CIR)** | операционные расходы / доходы | эффективность | <45% хорошо | coincident |
| **Комиссионный доход** | fee income | заработок вне процентов | — | coincident |
| **NII sensitivity** | Δ ЧПД при сдвиге ставки на 100 б.п. | процентный риск | раскрывается компанией | leading |
| **ROE** | чистая прибыль / капитал | отдача на капитал | 20–25% у топов | lagging |
| **P/B** | капитализация / капитал | оценка | 0,8–1,3x | — |

### Ключевые формулы

```
NIM = (Процентные доходы − Процентные расходы) / Средние процентные активы

Прибыль ≈ ЧПД + Комиссии − Опер. расходы − Резервы − Налог

Резервы = Средний портфель × Cost of Risk
```

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Ключевая ставка ↑ | активы переоцениваются быстрее пассивов | NIM ↑, затем ↓ | **с разворотом во времени** | 1–2 кв, разворот 3–6 кв |
| Ключевая ставка ↑ | кредит дороже → спрос падает | выдачи ↓ | пороговая | 2–3 кв |
| Охлаждение экономики | заёмщики хуже платят | CoR ↑, NPL ↑ | нелинейная | **2–4 кв** |
| Кредитный импульс ↓ | опережает спад | будущий рост портфеля ↓ | линейная | 3–4 кв |
| Безработица ↑ | розница не обслуживает долг | розничный NPL ↑ | нелинейная | 2–4 кв |
| Ставка ↓ (цикл смягчения) | дешевеет фондирование, оживают выдачи | объём ↑, NIM ↓ | асимметричная | 2–4 кв |

### Главный механизм: почему «высокая ставка = хорошо для банка» — полуправда

```
Фаза 1 (кварталы 1–2):  ставка ↑ → кредиты переоценились быстро,
                        депозиты ещё старые дешёвые → NIM РАСТЁТ, прибыль рекордная

Фаза 2 (кварталы 3–6):  вкладчики переложились в дорогие депозиты
                        → стоимость фондирования догоняет → NIM СЖИМАЕТСЯ

Фаза 3 (кварталы 4–8):  кредиты, выданные на пике ставки, начинают дефолтить
                        → CoR РАСТЁТ → прибыль падает
```

**Вывод для инвестора:** пик отчётной прибыли банка в цикле высокой ставки — часто худший
момент для входа, потому что впереди сжатие маржи и рост резервов. Международные
исследования (IMF) прямо указывают: сверхприбыли банков после цикла роста ставок носят
циклический характер и убывают, а кредитные потери приходят с лагом.

**Расщепление по структуре фондирования — ключ к сравнению банков:**

| Профиль банка | Реакция на рост ставки |
|---|---|
| Много дешёвых текущих счетов (высокий CASA) | выигрывает: фондирование почти не дорожает |
| Дорогое срочное/оптовое фондирование | проигрывает: расходы растут быстрее доходов |
| Много активов с плавающей ставкой | выигрывает быстро |
| Длинный портфель с фиксированной ставкой | проигрывает: доходы не растут, расходы растут |

### Пример

> Банк: портфель 10 трлн, CoR вырос с 1,2% до 2,0%.
> Дополнительные резервы = 10 трлн × 0,8 п.п. = **80 млрд руб.** прямого удара по прибыли.
> При прибыли 400 млрд это −20%, даже если NIM не изменился.

### Типичные ошибки

- Применять единый знак эффекта ставки ко всем банкам — он зависит от структуры фондирования.
- Считать текущий низкий NPL признаком качества портфеля: NPL запаздывает на 2–4 квартала.
- Путать рост портфеля с ростом прибыли: портфель может расти, а маржа сжиматься.
- Игнорировать Stage 2 — он предупреждает о будущем Stage 3.

## 3.2. НЕФТЕГАЗ

**Что определяет бизнес.** Рублёвая цена барреля и налоговый режим. Физические объёмы
ограничены квотами и инфраструктурой, поэтому основная динамика идёт от цены и курса.

### Метрики

| Метрика | Формула / определение | Что измеряет | Тип |
|---|---|---|---|
| **Добыча** | млн т, млрд м³ | физический объём | coincident |
| **Экспорт** | объём поставок за рубеж | доступ к рынкам | coincident |
| **Переработка** | объём нефти на НПЗ | глубина цепочки | coincident |
| **Refinery utilization** | загрузка НПЗ, % мощности | эффективность переработки | coincident |
| **Lifting cost** | операционные затраты на добычу / т | себестоимость подъёма | coincident |
| **F&D cost** | затраты на разведку и обустройство / т запасов | цена прироста запасов | lagging |
| **Reserve life** | запасы / годовая добыча | на сколько лет хватит | lagging |
| **Reserve replacement ratio** | прирост запасов / добыча | восполняет ли запасы | >100% = да | lagging |
| **Realized price** | фактическая цена реализации | что реально получили | coincident |
| **Дисконт Urals/ESPO к Brent** | Brent − Urals, $/барр | санкционная скидка | leading |
| **Netback** | цена − транспорт − пошлины − налоги | что доходит до компании | coincident |
| **EBITDA/барр** | EBITDA / добыча | маржа на баррель | coincident |
| **Net Debt / EBITDA** | чистый долг / EBITDA | долговая нагрузка | <1,5x комфортно | coincident |
| **Payout** | дивиденды / прибыль | сколько отдают акционеру | — |

### Ключевые формулы

```
Рублёвая цена барреля = Urals ($/барр) × Курс (руб/$)

Netback = Мировая цена − Дисконт − Логистика − Экспортная пошлина − НДПИ

НДПИ на нефть ≈ Кц × базовая ставка − вычеты,
где Кц привязан к цене Urals и курсу
```

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Urals ↑ | прямо в выручку | рублёвая выручка ↑ | линейная | немедленно |
| Рубль ↓ | та же валютная выручка = больше рублей | выручка, EBITDA ↑ | линейная | немедленно |
| Дисконт ↑ | реализованная цена ниже котировки | netback ↓ | линейная | 1 мес |
| НДПИ / пошлины ↑ | прямое изъятие | FCF ↓ | линейная | немедленно |
| Демпфер | компенсация за поставку топлива на внутренний рынок | маржа переработки | пороговая (обнуление при превышении цены) | 1 мес |
| Ставка ↑ | дорожает финансирование CAPEX | инвестпрограмма ↓ | линейная | 2–4 кв |

### Особенности налогового контура

- **Демпфер** — выплата из бюджета переработчикам за поставку топлива внутри страны по
  ценам ниже экспортных. Обнуляется, если внутренняя цена превышает индикативную на
  установленный порог. Масштаб механизма — сотни миллиардов и триллионы рублей в год,
  поэтому изменения его параметров критичны для НПЗ.
- **Налоговая котировка Urals** может отличаться от рыночной: с 2025 применяется
  взвешенная формула по портам, а дисконт к Brent в формуле ограничен предельной величиной.

### Пример

> Компания добывает 100 млн барр/год. Urals $60, курс 80 руб/$.
> Рублёвая выручка на баррель = 60 × 80 = **4 800 руб.**
> Курс ослаб до 92 при падении Urals до $55:
> 55 × 92 = **5 060 руб.** — выручка в рублях выросла, несмотря на падение долларовой цены.

### Типичные ошибки

- Смотреть на Brent вместо Urals × курс.
- Игнорировать дисконт: он определяет реально полученную цену.
- Не учитывать, что рост цены частично изымается через НДПИ (растёт налоговая база).
- Забывать демпфер при анализе компаний с большой переработкой.

## 3.3. ЧЁРНАЯ МЕТАЛЛУРГИЯ

**Что определяет бизнес.** Спред между ценой стали и корзиной сырья, умноженный на объём.
Спрос почти целиком завязан на инвестиционный цикл.

### Метрики

| Метрика | Формула / определение | Что измеряет | Тип |
|---|---|---|---|
| **Производство стали** | млн т | физический объём | coincident |
| **Отгрузки** | млн т проданной продукции | реальные продажи | coincident |
| **Загрузка мощностей** | производство / мощность, % | эффективность | coincident |
| **Цена реализации** | руб/т | ценовая конъюнктура | coincident |
| **Cash cost / т** | денежная себестоимость тонны | эффективность | coincident |
| **EBITDA / тонна** | EBITDA / объём | маржа на единицу | coincident |
| **Unit spread** | цена стали − корзина сырья | реальный заработок | **leading к марже** |
| **Доля экспорта** | экспорт / отгрузки | зависимость от курса | coincident |
| **Доля продукции с высокой добавленной стоимостью** | ВДС / отгрузки | качество портфеля | coincident |

### Ключевая формула

```
Unit spread = Цена стали
            − Железная руда
            − Коксующийся уголь
            − Электроэнергия
            − Логистика
```

Именно спред, а не цена стали, определяет прибыль. Металлург с собственной рудой и углём
(вертикально интегрированный) защищён от роста сырья; неинтегрированный — нет.

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Инвестиции в основной капитал ↑ | >90% спроса на сталь | отгрузки ↑ | **линейная** | 1–2 кв |
| Ставка ↑ | стройка и инвестпроекты замораживаются | внутренний спрос ↓ | пороговая | 2–4 кв |
| Рубль ↓ | экспортный паритет улучшается | рублёвая выручка ↑ | линейная | 1 кв |
| Цены на руду/уголь ↑ | растёт корзина сырья | спред ↓ | линейная | 1 кв |
| Тарифы РЖД ↑ | логистика дороже | спред ↓ | линейная | 1–2 кв |

### Операционный рычаг — почему падение больнее, чем кажется

```
Постоянные издержки высокие → при падении загрузки
удельная себестоимость растёт → маржа падает БЫСТРЕЕ выручки
```

Пример: выручка −15%, а EBITDA −40% — это нормальная реакция металлурга, а не аномалия.

### Пример

> Цена сляба 45 000 руб/т, корзина сырья 30 000 руб/т → спред 15 000 руб/т.
> Руда подорожала на 15% (+2 500 руб/т на тонну стали) при неизменной цене стали:
> спред падает до 12 500 руб/т, то есть **−17% к марже** при нулевом изменении цены продукции.

### Типичные ошибки

- Анализировать металлурга только по цене стали, игнорируя корзину сырья.
- Ждать, что инфраструктурные госпрограммы компенсируют заморозку частной стройки.
- Недооценивать операционный рычаг: маржа падает быстрее выручки.

## 3.4. ЦВЕТНАЯ МЕТАЛЛУРГИЯ И ЗОЛОТО

**Что определяет бизнес.** Мировая цена металла × курс минус себестоимость добычи.
Ключевой параметр качества актива — содержание металла в руде и полная себестоимость.

### Метрики

| Метрика | Формула / определение | Что измеряет | Тип |
|---|---|---|---|
| **Цена металла (LME)** | $/т или $/унц | конъюнктура | leading |
| **Производство** | т, унции | объём | coincident |
| **Ore grade** | содержание металла в руде, г/т или % | качество месторождения | lagging |
| **Recovery rate** | извлечено / содержалось, % | эффективность обогащения | coincident |
| **Cash cost (TCC)** | денежные затраты на производство унции/тонны | базовая себестоимость | coincident |
| **AISC** | Cash cost + поддерживающий CAPEX + админрасходы + роялти | **полная** себестоимость | coincident |
| **Mine life** | запасы / годовая добыча | срок жизни актива | lagging |
| **TC/RC** | плата за переработку концентрата | издержки для добытчика | coincident |
| **Realized price** | фактическая цена продажи | с учётом хеджей и премий | coincident |

### Ключевая формула

```
Маржа на унцию = Цена золота − AISC

AISC = Cash cost + Sustaining CAPEX + G&A + Роялти/НДПИ
```

**Важно:** AISC растёт вместе с ценой металла, потому что НДПИ и роялти считаются от цены.
Значит маржа растёт **медленнее**, чем цена — часть выигрыша самооблагается.

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Цена металла ↑ | прямо в выручку | выручка ↑ | линейная | немедленно |
| Рубль ↓ | валютная выручка, рублёвые издержки | маржа ↑↑ | линейная, усиливающая | немедленно |
| Рубль ↑ (крепкий) | съедает рост мировой цены | рублёвая выручка стоит | линейная | немедленно |
| Реальные ставки США ↓ | золото дорожает (нет альтернативной доходности) | цена золота ↑ | обратная | 1–2 кв |
| Геополитический риск ↑ | спрос на защитный актив | цена золота ↑ | скачкообразная | немедленно |
| Спрос Китая (для меди/никеля) | главный потребитель | цена ↑/↓ | линейная | 1–2 кв |

### Пример

> Золотодобытчик: цена золота выросла с $2 000 до $2 400 (+20%), AISC вырос с $1 200 до
> $1 320 (+10% через рост НДПИ от цены).
> Маржа: было 800, стало 1 080 → **+35%**.
> Но если рубль укрепился на 15%, рублёвая маржа выросла лишь на ~15% — курс съел половину.

### Типичные ошибки

- Смотреть на долларовую цену без курса.
- Использовать cash cost вместо AISC — он занижает реальную себестоимость.
- Игнорировать, что рост цены частично изымается через НДПИ.
- Не учитывать хеджирование: реализованная цена может сильно отличаться от спота.

## 3.5. УГОЛЬ

**Что определяет бизнес.** Не мировая цена, а **нетбэк**: сколько остаётся после вычета
логистики, которая съедает основную часть цены.

### Метрики

| Метрика | Формула / определение | Что измеряет | Тип |
|---|---|---|---|
| **Добыча** | млн т | объём | coincident |
| **Экспорт** | млн т за рубеж | доступ к премиальным рынкам | coincident |
| **Цена коксующегося угля** | $/т | для металлургии | leading |
| **Цена энергетического угля** | $/т | для генерации | leading |
| **Дисконт к бенчмарку** | бенчмарк − фактическая цена | санкционная/логистическая скидка | coincident |
| **Логистическая составляющая** | доля транспорта в цене, % | главный убийца маржи (40–60%) | coincident |
| **Нетбэк** | цена − пошлина − ж/д тариф − перевалка | что доходит до шахты | coincident |
| **Квоты Восточного полигона** | согласованный объём вывоза | физическое ограничение экспорта | leading |

### Ключевая формула

```
Нетбэк = Мировая цена
       − Экспортная пошлина
       − Тариф РЖД
       − Перевалка в порту
       − Дисконт

При низких мировых ценах нетбэк может стать ОТРИЦАТЕЛЬНЫМ
```

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Мировая цена ↑ | прямо в нетбэк | маржа ↑ | линейная, но с большим вычетом | 1 мес |
| Тариф РЖД ↑ | съедает нетбэк | маржа ↓↓ | линейная, сильная | 1 кв |
| Рубль ↓ | валютная выручка при рублёвых издержках | маржа ↑ | линейная | 1 кв |
| Ставка ↑ | закредитованные добивает | прибыль ↓ | линейная | 1–2 кв |
| Квоты на вывоз | физический потолок объёма | экспорт | ступенчатая | сразу при изменении |

### Внутриотраслевое расслоение

| Профиль | Положение |
|---|---|
| Коксующийся уголь + собственная логистика/порт | устойчивее всех |
| Энергетический уголь без своей логистики | теряет больше всего на нетбэке |
| Высокий долг + удалённое расположение | зона риска |

### Типичные ошибки

- Смотреть на мировую цену угля без вычета логистики и дисконта.
- Не различать коксующийся и энергетический уголь — у них разные рынки и циклы.
- Игнорировать пропускную способность железной дороги как физический потолок.

## 3.6. ПРОДУКТОВЫЙ РИТЕЙЛ

**Что определяет бизнес.** LFL-продажи, которые раскладываются на трафик и средний чек.
Это главная аналитика сектора.

### Метрики

| Метрика | Формула / определение | Что измеряет | Ориентир | Тип |
|---|---|---|---|---|
| **LFL (сопоставимые продажи)** | рост продаж магазинов, работающих >12 мес | органический рост без учёта новых точек | — | coincident |
| **Трафик** | число чеков в сопоставимых магазинах | сколько людей пришло | — | **leading** |
| **Средний чек** | выручка / число чеков | сколько тратят за визит | — | coincident |
| **Валовая маржа** | (выручка − себестоимость) / выручка | наценка | 22–25% | coincident |
| **Оборачиваемость запасов** | себестоимость / средние запасы | скорость продажи товара | — | coincident |
| **Потери (shrinkage)** | списания / выручка | воровство, порча, просрочка | 1–2% | lagging |
| **SG&A / выручка** | коммерческие и админрасходы к выручке | контроль издержек | — | coincident |
| **Аренда / выручка** | арендные платежи к выручке | нагрузка на маржу | — | coincident |
| **Выручка на м²** | выручка / торговая площадь | эффективность площади | — | coincident |
| **Доля СТМ** | собственные торговые марки / выручка | рычаг маржи | растёт к 20%+ | coincident |
| **Число магазинов, площадь** | шт., тыс. м² | экстенсивный рост | — | coincident |

### Ключевая формула

```
LFL = Трафик × Средний чек

Выручка = LFL-выручка + Выручка новых магазинов
```

**Декомпозиция — главный инструмент.** Три разных ситуации при одинаковом LFL +8%:

| Трафик | Чек | Что означает |
|---|---|---|
| +3% | +5% | здоровый рост: людей больше и тратят больше |
| −2% | +10% | рост только на инфляции, поток уходит — тревога |
| +8% | 0% | привлекают низкой ценой, маржа под давлением |

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Продуктовая инфляция ↑ | цены на полке растут | средний чек ↑ | линейная | 1 мес |
| Реальные доходы ↓ | покупательная способность падает | трафик ↓, trade-down | нелинейная | 1–2 кв |
| Инфляция замедляется | уходит инфляционная подпитка выручки | LFL ↓ | линейная | 1–2 кв |
| Ставка ↑ | дорожает долг и инвестпрограмма | прибыль ↓ | линейная | 1–2 кв |
| Зарплаты ↑ | ФОТ — крупная статья | SG&A ↑, маржа ↓ | линейная | 1–2 кв |

**Контринтуитивный момент:** замедление инфляции — это **риск** для ритейла, а не благо.
Рублёвый рост выручки во многом питался ростом цен; при дезинфляции и слабом трафике
темпы роста резко замедляются.

### Пример

> Сеть: LFL +8% = трафик −2% + чек +10%. Инфляция замедляется с 10% до 5%.
> При сохранении оттока трафика LFL падает примерно до +3% — рост выручки
> **сокращается почти втрое** без единого изменения в операционной работе.

### Типичные ошибки

- Смотреть на LFL целиком, не раскладывая на трафик и чек.
- Считать ритейл бенефициаром инфляции: выручка растёт, но зарплаты и аренда тоже.
- Игнорировать формат: дискаунтер в спад выигрывает, гипермаркет теряет.

## 3.7. ДИСКРЕЦИОННЫЙ (НЕПРОДОВОЛЬСТВЕННЫЙ) РИТЕЙЛ

**Что определяет бизнес.** Циклический спрос на необязательные покупки. Эластичность по
доходу выше единицы — падает глубже доходов и восстанавливается быстрее.

### Метрики

Базовый набор тот же, что у продуктового (LFL, трафик, чек, маржа, оборачиваемость), плюс
специфика:

| Метрика | Что измеряет | Почему важна |
|---|---|---|
| **Доля импорта в себестоимости** | валютная зависимость | определяет удар от курса |
| **Доля кредитных продаж** | покупки в рассрочку/кредит | чувствительность к ставке |
| **Сезонность (доля Q4)** | концентрация продаж | искажает квартальные сравнения |
| **Оборачиваемость запасов** | скорость распродажи | риск затоваривания и уценок |

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Реальные доходы ↓ | покупка откладывается | продажи ↓↓ | эластичность >1 | 1–2 кв |
| Ставка по потребкредиту ↑ | техника и мебель покупаются в кредит | продажи ↓ | пороговая | 1–2 кв |
| Рубль ↓ | импортная себестоимость растёт | маржа ↓ или цена ↑ | асимметричная | 1–2 кв |
| Рубль ↑ (крепкий) | закупка дешевеет, но провоцирует уценки остатков | маржа неоднозначно | нелинейная | 1–2 кв |

### Типичные ошибки

- Переносить логику продуктового ритейла: здесь спрос откладываемый, а не обязательный.
- Не различать закредитованность внутри сектора: при высокой ставке она решает всё.

## 3.8. E-COMMERCE / МАРКЕТПЛЕЙСЫ

**Что определяет бизнес.** GMV (оборот) и take rate (доля площадки в этом обороте).
Прибыль появляется, когда монетизация растёт быстрее логистических издержек.

### Метрики

| Метрика | Формула / определение | Что измеряет | Тип |
|---|---|---|---|
| **GMV** | суммарная стоимость всех заказов | размер оборота через площадку | coincident |
| **Take rate** | выручка площадки / GMV | сколько площадка забирает себе | coincident |
| **Число заказов** | шт. | активность | coincident |
| **Средний чек** | GMV / число заказов | стоимость покупки | coincident |
| **Активные покупатели** | уникальные покупатели за 12 мес | база клиентов | **leading** |
| **Частота заказов** | заказы / активный покупатель | лояльность | **leading** |
| **Contribution margin** | выручка − прямые переменные издержки | зарабатывает ли заказ | coincident |
| **Стоимость доставки на заказ** | логистические расходы / заказы | эффективность склада и доставки | coincident |
| **Доля 3P** | оборот сторонних продавцов / GMV | модель (маркетплейс vs магазин) | coincident |
| **CAC / LTV** | стоимость привлечения / ценность клиента | окупаемость маркетинга | leading |
| **Выручка финтеха** | доходы встроенного банка | второй мотор бизнеса | coincident |
| **CoR по кредитам селлерам** | резервы / портфель | риск финтех-сегмента | lagging |

### Ключевые формулы

```
Выручка площадки = GMV × Take rate

GMV = Активные покупатели × Частота заказов × Средний чек

Юнит-экономика = Take rate − Логистика − Обработка − Маркетинг на заказ
```

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Реальные доходы ↓ | меньше покупок | GMV замедляется | эластичность ~1 | 1–2 кв |
| Проникновение онлайна ↑ | структурный сдвиг | GMV ↑ | **структурный, не циклический** | годы |
| Ставка ↑ | процентный доход на остатки клиентов | финтех-выручка ↑ | линейная | 1 кв |
| Ставка ↑ | ухудшается платёжеспособность селлеров | CoR финтеха ↑ | нелинейная | 2–4 кв |
| Ставка ↑ | дорожают деньги для убыточных конкурентов | конкурентное давление ↓ | пороговая | 2–4 кв |
| Топливо/логистика ↑ | доставка дороже | contribution margin ↓ | линейная | 1 кв |

**Двойственность финтеха.** Встроенный банк — одновременно главный драйвер прибыли (доход
на остатки при высокой ставке) и главный риск (кредитование селлеров высокорисковое,
стоимость риска растёт при охлаждении экономики).

### Пример

> GMV 4 трлн, take rate 8% → выручка 320 млрд.
> Take rate вырос до 10% при том же GMV → выручка 400 млрд, **+25% без роста оборота**.
> Именно рост монетизации, а не GMV, переводит маркетплейс в прибыль.

### Типичные ошибки

- Оценивать по GMV без юнит-экономики: оборот может расти при убытке на каждом заказе.
- Игнорировать кредитный риск финтех-сегмента.
- Считать рост GMV чисто циклическим — в нём большая структурная компонента.

## 3.9. IT / СОФТ

**Что определяет бизнес.** Повторяющаяся выручка (подписки, лицензии) и её удержание.
Макро бьёт по этому сектору **двумя разными путями одновременно**.

### Метрики

| Метрика | Формула / определение | Что измеряет | Ориентир | Тип |
|---|---|---|---|---|
| **ARR** | годовая повторяющаяся выручка | база бизнеса | — | coincident |
| **MRR** | месячная повторяющаяся выручка | то же помесячно | — | coincident |
| **Bookings** | сумма подписанных контрактов | будущая выручка | — | **leading** |
| **Отгрузки** | переданные лицензии (для РФ важно) | опережают признание выручки | — | **leading** |
| **RPO** | законтрактованная, но не признанная выручка | видимость будущего | — | **leading** |
| **NRR** | выручка от старых клиентов сейчас / год назад | рост внутри базы | >100% хорошо, >120% отлично | leading |
| **GRR** | то же без учёта допродаж | удержание | <85% тревожно | leading |
| **Churn** | ушедшие клиенты / база | отток | — | leading |
| **ARPU / ARPA** | выручка на клиента | монетизация | — | coincident |
| **CAC** | затраты на продажи и маркетинг / новые клиенты | цена привлечения | — | coincident |
| **CAC payback** | CAC / валовая прибыль на клиента в месяц | за сколько окупается клиент | <18 мес хорошо | leading |
| **Валовая маржа** | (выручка − себестоимость) / выручка | экономика продукта | 70–85% | coincident |
| **R&D / выручка** | расходы на разработку | инвестиции в продукт | — | coincident |
| **Rule of 40** | рост выручки % + маржа % | баланс роста и прибыльности | ≥40 хорошо | coincident |

### Ключевые формулы

```
ARR = Число клиентов × Средний годовой платёж

NRR = (ARR старых клиентов на конец периода) / (ARR тех же клиентов на начало)

Rule of 40 = Рост выручки (%) + EBITDA margin (%)
```

### Связь с макро — двойной удар

```
СЛОЙ 1 — ОЦЕНКА
ставка ↑ → ставка дисконтирования ↑ → «длинные» денежные потоки
обесцениваются сильнее → мультипликаторы сжимаются

СЛОЙ 2 — СПРОС (его обычно забывают)
кризис / высокая ставка → корпоративные клиенты режут IT-бюджеты
ОДНИМИ ИЗ ПЕРВЫХ → отгрузки и выручка падают
```

Второй слой бьёт по операционным показателям **поверх** эффекта на оценку. Это ключевое
отличие IT: у нефтяника ставка трогает в основном оценку, у софта — и оценку, и выручку.

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Ставка ↑ | дисконтирование длинных потоков | мультипликаторы ↓ | линейная, сильная | немедленно |
| Деловая активность ↓ | режут IT-бюджеты | bookings, отгрузки ↓ | **проциклическая, >1** | 1–2 кв |
| Импортозамещение | обязательный спрос на отечественный софт | ARR ↑ | структурный | годы |
| Зарплаты в IT ↑ | ФОТ — основная статья | маржа ↓ | линейная | 1–2 кв |

**Сезонность.** В России до 40%+ годовых отгрузок приходится на IV квартал (бюджетные
циклы заказчиков). Экстраполировать Q1–Q3 на год нельзя.

### Пример

> Компания: ARR 10 млрд, NRR 115%. Без единого нового клиента следующий год даёт
> 11,5 млрд. Но если корпораты режут бюджеты и NRR падает до 95% — база сжимается до
> 9,5 млрд, то есть **−17% к ожиданию** при том же числе клиентов.

### Типичные ошибки

- Учитывать только эффект ставки на оценку, забывая процикличность IT-бюджетов.
- Смотреть на выручку без отгрузок и RPO — они опережают.
- Экстраполировать квартал на год при сильной сезонности.

## 3.10. ИНТЕРНЕТ / РЕКЛАМА / КЛАССИФАЙДЫ

**Что определяет бизнес.** Рекламные и сервисные бюджеты, которые процикличны, плюс
специфика площадки (вакансии, объявления недвижимости).

### Метрики

| Метрика | Формула / определение | Что измеряет | Тип |
|---|---|---|---|
| **DAU / MAU** | дневная / месячная аудитория | охват | coincident |
| **Stickiness** | DAU / MAU | вовлечённость | coincident |
| **Платящие клиенты** | число компаний-клиентов | монетизируемая база | coincident |
| **ARPPU** | выручка / платящий клиент | глубина монетизации | coincident |
| **Доля рекламных доходов** | реклама / выручка | цикличность бизнеса | — |
| **Число вакансий / резюме** (job) | шт. | состояние рынка труда | **leading для экономики** |
| **hh-индекс** | резюме / вакансии | напряжённость рынка труда | **leading** |
| **Число объявлений / лидов** (недвижимость) | шт. | активность рынка жилья | leading |

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Деловая активность ↓ | рекламу режут первой | выручка ↓ | проциклическая, >1 | 1–2 кв |
| Рынок труда охлаждается | вакансий меньше | выручка job-площадки ↓ | линейная | 1–2 кв |
| Ставка ↑ | сделок с жильём меньше | лиды и выручка классифайда недвижимости ↓ | пороговая | 2–3 кв |
| Перегрев рынка труда | компании борются за кадры | выручка job-площадки ↑↑ | нелинейная | 1 кв |

**Особенность job-классифайда:** он одновременно бизнес и **опережающий индикатор
экономики**. Падение числа вакансий видно раньше, чем рост безработицы в статистике.
То есть отчётность такой компании — это ещё и сигнал по всему рынку.

### Типичные ошибки

- Считать job-площадку чисто растущей историей: она жёстко привязана к циклу рынка труда.
- Игнорировать процикличность рекламы — она падает быстрее ВВП.

## 3.11. ТЕЛЕКОМ

**Что определяет бизнес.** Абонентская база × ARPU при почти насыщенном рынке. Основная
интрига — не рост, а долговая нагрузка и тарифное регулирование.

### Метрики

| Метрика | Формула / определение | Что измеряет | Ориентир | Тип |
|---|---|---|---|---|
| **Абоненты** | число активных SIM/подключений | база | — | coincident |
| **Gross adds** | новые подключения за период | приток | — | leading |
| **Net adds** | подключения − отключения | чистый прирост | — | leading |
| **Churn** | отключения / база | отток | 30–40%/год (мобайл РФ) | coincident |
| **ARPU** | выручка / средний абонент | монетизация | — | coincident |
| **Потребление данных** | ГБ на абонента | нагрузка и ценность услуги | двузначный рост | coincident |
| **Загрузка сети** | % использования мощности | потребность в CAPEX | — | leading для CAPEX |
| **EBITDA margin** | EBITDA / выручка | эффективность | ~40%+ | coincident |
| **CAPEX / выручка** | инвестиции к выручке | капиталоёмкость | 18–22% | coincident |
| **Net Debt / EBITDA** | долговая нагрузка | устойчивость | — | coincident |
| **Экосистемная выручка** | финтех, медиа, облака | новые точки роста | — | coincident |

### Ключевая формула

```
Выручка = Абоненты × ARPU

FCF = EBITDA − CAPEX − Проценты − Налоги − Δоборотный капитал
```

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Ставка ↑ | большой долг, часто плавающий | процентные расходы ↑↑, FCF ↓ | линейная, сильная | 1–2 кв |
| Ставка ↓ | обратный эффект | прибыль ↑ | линейная | 1–2 кв |
| Инфляция ↑ | издержки растут | маржа ↓ (если тариф не индексируют) | линейная | 1–2 кв |
| Тарифное регулирование | ограничение индексации | ARPU ↓ в реальном выражении | ступенчатая | сразу |
| Рубль ↓ | оборудование импортное | CAPEX ↑ | линейная | 2–4 кв |
| Реальные доходы ↓ | связь — базовая услуга | ARPU почти не падает | эластичность <1 | — |

**Ключ к пониманию:** телеком — это «квазиоблигация». Операционно стабилен, но
чувствителен к ставке через долг. Поэтому снижение ставки для него — прямой позитив в
прибыли, а не операционная история.

### Типичные ошибки

- Оценивать по дивидендной доходности без анализа долговой устойчивости.
- Игнорировать конфликт «дивиденды в долг»: выплаты финансируются заимствованиями.
- Не учитывать тарифные ограничения регулятора при прогнозе ARPU.

## 3.12. ЭЛЕКТРОЭНЕРГЕТИКА

**Что определяет бизнес.** Регулируемые механизмы: тариф, плата за мощность, доходность
на инвестированный капитал. Спрос защитный, поэтому цикличность низкая.

### Метрики

| Сегмент | Метрика | Что измеряет | Тип |
|---|---|---|---|
| Генерация | **Установленная мощность** (МВт) | масштаб | coincident |
| Генерация | **Выработка** (млн кВт·ч) | объём производства | coincident |
| Генерация | **КИУМ** | загрузка мощности, % | coincident |
| Генерация | **Цена РСВ** | цена на рынке на сутки вперёд | coincident |
| Генерация | **Платежи ДПМ / КОММод** | повышенный тариф за новую мощность | **leading для потоков** |
| Генерация | **Топливная составляющая** | доля газа/угля в себестоимости | coincident |
| Сети | **RAB** | регулируемая база инвестированного капитала | coincident |
| Сети | **Allowed return** | разрешённая доходность на RAB | leading |
| Сети | **Полезный отпуск** | переданная потребителям энергия | coincident |
| Сети | **Потери в сетях** | % потерь | coincident |
| Сети | **Плата за техприсоединение** | доход от новых подключений | leading |
| Сбыты | **Дебиторская задолженность** | платёжная дисциплина | lagging |

### Ключевые формулы

```
Выручка генератора = Продажа энергии (объём × цена РСВ)
                   + Продажа мощности (в т.ч. по ДПМ/КОММод)

Выручка сети ≈ RAB × Allowed return + возврат капитала + операционные расходы
```

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Промышленное производство ↑ | больше потребления | выработка, отпуск ↑ | линейная, слабая | 1 кв |
| Цена газа ↑ (регулируемая) | топливо — главная статья | маржа генерации ↓ | линейная | сразу при индексации |
| Ставка ↑ | у cash-rich растёт процентный доход | прибыль ↑ | **обратный знак!** | 1 кв |
| Ставка ↑ | у закредитованных с большой стройкой | прибыль ↓ | линейная | 1–2 кв |
| Окончание ДПМ | обрыв повышенного тарифа | выручка ↓↓ | **ступенчатая** | в дату окончания |
| Инфляция ↑ | тариф индексируется с лагом | маржа ↓ временно | линейная | 1–2 кв |

**Два парадокса сектора:**

1. **Снижение ставки может быть негативом** — для генератора с большой денежной подушкой
   процентный доход падает.
2. **Окончание платежей за мощность — обрыв, а не плавное снижение.** Нужно смотреть
   график истечения ДПМ по каждому объекту: после даты выручка падает ступенькой.

### Типичные ошибки

- Считать снижение ставки безусловным плюсом для всей энергетики.
- Игнорировать график истечения ДПМ — это самый предсказуемый и самый упускаемый риск.
- Смешивать генерацию, сети и сбыты: у них разная экономика и разные драйверы.

## 3.13. УДОБРЕНИЯ И ХИМИЯ

**Что определяет бизнес.** Мировая цена продукта × курс минус себестоимость, в которой у
азотных производителей главное — газ.

### Метрики

| Метрика | Что измеряет | Тип |
|---|---|---|
| **Объём производства и продаж** (по видам) | физический объём | coincident |
| **Цены DAP/MAP, карбамид, калий** | конъюнктура по видам | leading |
| **Доля газа в себестоимости** | ключевая уязвимость азотных (обычно 50–70% себестоимости аммиака/карбамида) | coincident |
| **Загрузка мощностей** | эффективность | coincident |
| **Экспортные пошлины и квоты** | изъятие и ограничение объёма | ступенчатая |
| **Себестоимость на тонну** | конкурентоспособность | coincident |

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Мировые цены на удобрения ↑ | прямо в выручку | выручка ↑ | линейная | 1 мес |
| Цена газа в Европе ↑ | мировая себестоимость азотных растёт → цены растут | маржа российских ↑↑ | **усиливающая** | 1–2 кв |
| Внутренняя цена газа ↑ | себестоимость азотных растёт | маржа ↓ | линейная | сразу |
| Рубль ↓ | валютная выручка | рублёвая маржа ↑ | линейная | 1 мес |
| Цены на зерно ↑ | фермеры богаче → покупают больше удобрений | спрос ↑ | линейная | 1–2 сезона |
| Экспортные пошлины | прямое изъятие | FCF ↓ | ступенчатая | сразу |

**Ключевой механизм — газовый мультипликатор.** Российский производитель азотных
удобрений покупает газ по регулируемой внутренней цене, а продаёт продукт по мировой,
которая формируется под европейские газовые издержки. Рост цен на газ в Европе поднимает
мировую цену удобрений, не увеличивая российскую себестоимость → сверхмаржа. Обратная
сторона: либерализация внутренних цен на газ — структурный риск для этой модели.

### Типичные ошибки

- Не различать азотные, фосфорные и калийные цепочки: у них разное сырьё и разные циклы.
- Игнорировать газовый канал — он объясняет большую часть волатильности маржи.

## 3.14. ТРАНСПОРТ

Четыре подсектора с принципиально разной экономикой — разбирать раздельно.

### 3.14.1. Авиаперевозки

| Метрика | Формула / определение | Что измеряет | Ориентир | Тип |
|---|---|---|---|---|
| **Пассажиропоток** | число перевезённых | объём | — | coincident |
| **RPK** | пассажиро-километры (платные) | реальная транспортная работа | — | coincident |
| **ASK** | предложенные кресло-километры | провозная ёмкость | — | coincident |
| **Load factor** | RPK / ASK | заполняемость | 85%+ у эффективных | coincident |
| **Yield** | выручка / RPK | доходность перевозки | — | coincident |
| **Стоимость топлива** | расходы на керосин | главная переменная статья | 30–40% расходов | coincident |
| **Лизинговые платежи** | аренда парка | фиксированная нагрузка | — | coincident |
| **Налёт часов** | использование ВС | эффективность парка | — | coincident |

```
Выручка = RPK × Yield = (ASK × Load factor) × Yield
```

| Фактор | Механизм | Вид | Оценка силы |
|---|---|---|---|
| Реальные доходы ↑ | авиабилет — дискреционная трата | эластичность **>1** | income-эластичность мирового трафика ~1,3–1,5 |
| Цена керосина ↑ | главная статья расходов | линейная, сильная | — |
| Рубль ↓ | лизинг, запчасти, обслуживание в валюте | линейная | — |
| Ставка ↑ | лизинг и долг дорожают | линейная | — |

**Особенность:** авиация — «luxury good» на уровне спроса. Растёт быстрее доходов на
подъёме и падает глубже в спад.

### 3.14.2. Морские перевозки

| Метрика | Что измеряет |
|---|---|
| **Фрахтовые ставки** | цена перевозки |
| **TCE (Time Charter Equivalent)** | чистая суточная доходность судна — ключевая метрика |
| **Загрузка флота** | доля работающих судов |
| **Тоннаж** | провозная способность |

Парадокс: рост фрахтовых ставок не всегда помогает конкретному перевозчику, если его флот
ограничен в работе. Смотреть надо на TCE и загрузку, а не на рыночный индекс фрахта.

### 3.14.3. Порты

|---|---|
| **Грузооборот** | объём перевалки, млн т |

Порт — самый защищённый актив в транспорте: зарабатывает на потоке независимо от того,

## 3.15. АГРО И ПИЩЕПРОМ

**Что определяет бизнес.** Биологический цикл. Текущая выручка определяется решениями,
принятыми 1–3 года назад, а не сегодняшним спросом. Это уникальная черта сектора.

### Метрики

| Метрика | Что измеряет | Тип |
|---|---|---|
| **Посевные площади** | масштаб будущего урожая | **leading (на сезон вперёд)** |
| **Урожайность** (ц/га) | эффективность | coincident |
| **Валовой сбор** | физический результат | coincident |
| **Поголовье, привес** | база животноводства | leading |
| **Биологические активы** | стоимость живых активов по МСФО 41 | leading |
| **Биомасса в воде** (аквакультура) | будущий объём продаж через 1,5–2 года | **сильный leading** |
| **Себестоимость кормов** | главная статья животноводства | coincident |
| **Цены реализации** | конъюнктура | coincident |
| **Экспортные пошлины** | изъятие части экспортной цены | ступенчатая |

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Мировые цены на агропродукцию ↑ | экспортная выручка | выручка ↑ | линейная (за вычетом пошлины) | 1 сезон |
| Рубль ↓ | валютная выручка экспортёров | маржа ↑ | линейная | 1 кв |
| Экспортная пошлина ↑ | прямое изъятие | маржа ↓ | ступенчатая | сразу |
| Ставка ↑ | льготные кредиты АПК дорожают | процентные расходы ↑ | линейная | 1–2 кв |
| Цены на корма ↑ | себестоимость животноводства | маржа ↓ | линейная | 1–2 кв |

**Главная особенность.** Опережающий индикатор здесь физический: биомасса, поголовье,
посевные площади. Компания с растущей биомассой при падающей текущей выручке — это не
кризис, а инвестиционная фаза цикла. И наоборот.

### Типичные ошибки

- Оценивать по текущей выручке, игнорируя биологические активы.
- Забывать, что господдержка через льготные кредиты дорожает при высокой ставке.

### Метрики

**Фармпроизводитель:**

| **Доля ЖНВЛП** | часть портфеля с регулируемой ценой | coincident |
| **Доля госзакупок** | зависимость от бюджета | coincident |
| **Пайплайн** | препараты в разработке | **leading** |
| **Валовая маржа** | экономика продукта | coincident |

**Частная клиника:**

| Метрика | Что измеряет | Тип |
|---|---|---|

| **Выручка на врача / на клинику** | эффективность | coincident |

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Рубль ↑ (крепкий) | импортные субстанции и оборудование дешевеют | маржа ↑ | линейная | 1–2 кв |

| Регулирование цен ЖНВЛП | нельзя переложить инфляцию | маржа дешёвого сегмента ↓ | ступенчатая | сразу |
| Госзакупки ↑ | бюджетный спрос | выручка ↑ | линейная | 1–2 кв |
| Медицинская инфляция ↑ | можно повышать чек | выручка ↑ | линейная | 1–2 кв |

**Важное отличие от сырьевых секторов:** фарма — **«антиэкспортёр»**. Крепкий рубль для
неё плюс, потому что субстанции и оборудование импортные. При анализе портфеля это
естественный хедж к экспортёрам.

### Типичные ошибки

- Автоматически считать крепкий рубль негативом — для фармы он позитив.
- Игнорировать потолок цен ЖНВЛП при прогнозе маржи.

## 3.17. ЛИЗИНГ И МФО

**Что определяет бизнес.** Разница между стоимостью фондирования и доходностью портфеля
минус потери. По сути та же логика, что у банка, но с более коротким циклом.

### Метрики

| Метрика | Что измеряет | Тип |
|---|---|---|
| **Новый бизнес** | стоимость переданных в лизинг предметов | **leading** |
| **Лизинговый портфель** | накопленный объём | coincident |
| **ЧИЛ** (чистые инвестиции в лизинг) | балансовая величина требований | coincident |
| **Стоимость фондирования** | во сколько обходятся деньги | coincident |
| **Чистая процентная маржа** | заработок на разнице ставок | coincident |
| **Cost of Risk** | плата за риск | lagging |
| **Доля проблемных активов** | качество портфеля | lagging |

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Ставка ↑ | фондирование дороже, спрос на технику падает | новый бизнес ↓↓ | пороговая | 1–2 кв |
| Ставка ↓ | оживает инвестспрос | новый бизнес ↑↑ | **лизинг ускоряется одним из первых** | 1–2 кв |
| Инвестактивность бизнеса ↓ | технику не обновляют | новый бизнес ↓ | линейная | 1–2 кв |
| Охлаждение экономики | лизингополучатели дефолтят | CoR ↑ | нелинейная | 2–4 кв |

**Ключевая межсекторная цепочка:**

```
Ставка ↑ → автокредит дороже → продажи автомобилей ↓
         → лизинг автотранспорта ↓
         → страхование КАСКО ↓
```

Одно движение ставки задевает три сектора подряд. Автопродажи здесь — опережающий
индикатор и для лизинга, и для страховщиков.

**Асимметрия цикла:** лизинг режется одним из первых при ужесточении и восстанавливается
одним из первых при смягчении. Поэтому новый бизнес лизинговой компании — хороший ранний
сигнал разворота инвестиционного цикла.

## 3.18. СТРАХОВАНИЕ

**Что определяет бизнес.** Два независимых мотора: андеррайтинг (собрали премий больше,
чем выплатили) и инвестиционный доход от портфеля.

### Метрики

| Метрика | Формула | Что измеряет | Ориентир | Тип |
|---|---|---|---|---|
| **Страховые премии** | собранные взносы | объём бизнеса | — | coincident |
| **Коэффициент убыточности** | выплаты / премии | доля выплат | — | lagging |
| **Коэффициент расходов** | расходы / премии | стоимость ведения дела | — | coincident |
| **Комбинированный коэффициент** | убыточность + расходы | **прибылен ли андеррайтинг** | <100% = да | coincident |
| **Инвестиционный портфель** | активы под управлением | второй мотор | — | coincident |
| **Дюрация портфеля** | средний срок облигаций | чувствительность к ставке | — | leading |
| **RoATE** | доход на средний капитал | отдача | — | lagging |

### Ключевая формула

```
Прибыль = Андеррайтинговый результат + Инвестиционный доход

Андеррайтинговый результат = Премии × (1 − Комбинированный коэффициент)
```

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Ставка ↓ | облигации в портфеле дорожают | прибыль ↑↑ | **сильная, немедленная** | сразу |
| Ставка ↑ | облигации дешевеют (бумажный убыток) | прибыль ↓ | **та же связь в обратную сторону** | сразу |
| Ставка ↑ (устойчиво) | реинвестирование под высокую доходность | будущий доход ↑ | обратная в долгосроке | 4+ кв |
| Автокредитование ↓ | меньше новых машин | премии КАСКО ↓ | линейная | 1–2 кв |
| Инфляция ↑ | ремонт и запчасти дорожают | убыточность ↑ | линейная | 2–4 кв |
| Реальные доходы ↑ | растёт накопительное страхование | премии life ↑ | эластичность >1 | 1–2 кв |

**Двусторонняя чувствительность — главное, что упускают.** Страховщик с большим
облигационным портфелем — это фактически ставка на снижение ключевой ставки. Но
механизм работает в обе стороны: рост ставки даёт бумажный убыток от переоценки. Чем
длиннее дюрация портфеля, тем сильнее качели.

### Типичные ошибки

- Оценивать страховщика только по премиям, игнорируя инвестпортфель.
- Забывать про двустороннюю переоценку облигаций.

## 3.19. ДЕВЕЛОПМЕНТ

**Что определяет бизнес.** Доступность ипотеки. Связь с ставкой — самая сильная и самая
нелинейная во всей методичке.

### Метрики

| Метрика | Формула / определение | Что измеряет | Тип |
|---|---|---|---|
| **Продажи (контрактация)** | м² и рубли | главный операционный показатель | coincident |
| **Цена за м²** | средняя цена реализации | ценовая динамика | coincident |
| **Запуски новых проектов** | м² выведенных в продажу | будущее предложение | **leading** |
| **Sales velocity** | скорость продаж, м²/мес на проект | спрос на конкретный продукт | leading |
| **Распроданность** | продано / всего в проекте, % | **управляет ставкой проектного финансирования** | coincident |
| **Нераспроданные остатки** | непроданные м² в готовых домах | замороженный капитал | lagging |
| **Себестоимость строительства** | руб/м² | издержки | coincident |
| **Маржа проекта** | (цена − себестоимость) / цена | экономика | coincident |
| **Наполнение эскроу** | средства покупателей на счетах | покрытие проектного долга | coincident |
| **Долг без эскроу / EBITDA** | реальная долговая нагрузка | устойчивость | coincident |
| **Земельный банк** | м² в собственности | будущие проекты | leading |

### Ключевой механизм: эскроу инвертирует логику ставки

```
Покупатель платит → деньги на эскроу-счёт (застройщик их пока не видит)
                  → банк даёт проектное финансирование под стройку

Чем БОЛЬШЕ денег на эскроу (выше распроданность),
тем НИЖЕ эффективная ставка по проектному финансированию

Проданные метры  → финансирование стоит дёшево (единицы процентов)
Непроданные      → финансирование по рыночной ставке (десятки процентов)
```

**Следствие:** высокая ставка бьёт по девелоперу **дважды**:
1. напрямую — ипотека дороже, спрос падает;
2. косвенно — низкая распроданность → дорогое проектное финансирование → процентные
   расходы съедают прибыль.

Поэтому распроданность — не второстепенная метрика, а фактически фактор стоимости долга.

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Ипотечная ставка ↑ | платёж растёт → доступность падает | продажи ↓↓ | **пороговая** | 1–2 кв |
| Льготные программы | отвязывают часть спроса от рыночной ставки | продажи держатся | ступенчатая | сразу при изменении параметров |
| Ключевая ставка ↑ | дорожает проектное финансирование | процентные расходы ↑ | линейная | 1–2 кв |
| Реальные доходы ↓ | падает платёжеспособность | спрос ↓ | линейная | 2–3 кв |
| Себестоимость стройки ↑ | материалы и рабочая сила | маржа проекта ↓ | линейная | 2–4 кв |

**Про пороговый характер.** Между ставками 8% и 12% спрос снижается плавно. Выше ~18%
рыночная ипотека фактически выключается: ежемесячный платёж перестаёт помещаться в
бюджет типичной семьи. Поэтому линейная экстраполяция «каждый +1 п.п. = −X% продаж»
неверна — надо смотреть, по какую сторону порога находится ставка.

### Пример

> Квартира 10 млн, первый взнос 20% → кредит 8 млн на 20 лет.
> При 8% годовых платёж ≈ 67 тыс. руб/мес.
> При 18% годовых платёж ≈ 123 тыс. руб/мес — **почти вдвое больше**.
> Доход, необходимый для одобрения, вырастает соответственно — отсекается основная часть
> покупателей. Это и есть порог, а не плавное снижение.

### Типичные ошибки

- Линейно пересчитывать эффект ставки без учёта порога.
- Игнорировать распроданность и механику эскроу — половина эффекта ставки идёт туда.
- Не различать льготный и рыночный сегменты спроса.

## 3.20. МАШИНОСТРОЕНИЕ И ПРОМЫШЛЕННОСТЬ

**Что определяет бизнес.** Портфель заказов. У госзаказных компаний — бюджетный цикл, у
рыночных — инвестиционная активность клиентов.

### Метрики

| Метрика | Что измеряет | Тип |
|---|---|---|
| **Backlog (портфель заказов)** | законтрактованная будущая выручка | **сильный leading** |
| **Покрытие backlog** | backlog / годовая выручка (в годах) | видимость будущего | leading |
| **Новые контракты за период** | приток заказов | leading |
| **Загрузка мощностей** | использование производства | coincident |
| **Доля госзаказа** | зависимость от бюджета | — |
| **Срок исполнения контракта** | длительность цикла | — |
| **Локализация** | доля отечественных комплектующих | устойчивость к санкциям | — |

### Связь с макро

| Фактор | Механизм | Метрика | Вид | Лаг |
|---|---|---|---|---|
| Госрасходы по профильной статье ↑ | прямой заказ | backlog ↑ | ступенчатая | 1–2 кв |
| Инвестиции в основной капитал ↓ | клиенты не обновляют оборудование | новые контракты ↓ | линейная | 2–4 кв |
| Ставка ↑ | клиенты режут CAPEX | заказы ↓ | линейная | 2–4 кв |
| Рубль ↓ | импортные комплектующие дорожают | себестоимость ↑ | линейная | 1–2 кв |

**Различие двух моделей:**

| Тип | Драйвер | Цикличность | Маржа |
|---|---|---|---|
| Госзаказный | бюджет | контрциклична (держит загрузку в спад) | регулируемая, низкая |
| Рыночный | инвестиции клиентов | проциклична | выше, но волатильна |

Смешивать их при анализе нельзя: это два разных бизнеса с противоположной реакцией на цикл.

# ЧАСТЬ 4. СВОДНАЯ ТАБЛИЦА: КТО К ЧЕМУ ЧУВСТВИТЕЛЕН

## 4.1. Главный драйвер по секторам

| Сектор | Драйвер №1 | Драйвер №2 | Главная метрика для слежения |
|---|---|---|---|
| Банки | ключевая ставка | качество заёмщиков | NIM, Cost of Risk |
| Нефтегаз | Urals × курс | налоговый режим | рублёвая цена барреля |
| Чёрная металлургия | инвестиции в основной капитал | цены на сырьё | unit spread |
| Цветмет и золото | мировая цена × курс | AISC | маржа на унцию/тонну |
| Уголь | логистика и тарифы | мировая цена | нетбэк |
| Продуктовый ритейл | реальные доходы | продуктовая инфляция | LFL (трафик × чек) |
| Дискреционный ритейл | реальные доходы | потребкредит, курс | LFL, оборачиваемость |
| E-commerce | проникновение онлайна | доходы | GMV × take rate |
| IT / софт | ставка (оценка) + IT-бюджеты | импортозамещение | ARR, NRR, отгрузки |
| Интернет / реклама | деловая активность | рынок труда | выручка, hh-индекс |
| Телеком | ставка (долг) | тарифное регулирование | ARPU, Net Debt/EBITDA |

| Авиа | реальные доходы | керосин, курс | load factor × yield |

| Лизинг / МФО | ставка | инвестактивность | новый бизнес |

| Девелопмент | ипотечная ставка | льготные программы | продажи м², распроданность |
| Машиностроение | госзаказ / инвестиции | — | backlog |

## 4.2. Кто как реагирует на рост ключевой ставки

| Реакция | Секторы | Механизм |
|---|---|---|
| **Сильный минус** | девелопмент, лизинг, дискреционный ритейл, закредитованный телеком | спрос + стоимость долга одновременно |
| **Минус через оценку** | IT / растущие компании | длинные потоки обесцениваются |
| **Смешанно** | банки | маржа сначала растёт, потом сжимается; риски растут с лагом |
| **Плюс** | компании с большой денежной подушкой, биржа, генераторы с кэшем | процентный доход на остатки |
| **Плюс, потом минус** | страхование | переоценка портфеля вниз сейчас, реинвестирование выше потом |
| **Почти нейтрально** | продуктовый ритейл, фарма, электросети | защитный спрос, регулируемая выручка |

| Реакция | Секторы |

# ЧАСТЬ 6. ФИСКАЛЬНЫЙ БЛОК

Государство влияет на компанию двумя разными способами с разными знаками — их нельзя
смешивать.

| | Что это | Знак для акционера |
|---|---|---|
| **След государства** | госрасходы, госзаказ, субсидии | часто **плюс** (спрос) |
| **Изъятие** | налоги, пошлины, квазиналоги | всегда **минус** (денежный поток) |

## 6.1. Налоговая карта по секторам

| Налог | Кого касается | Механика |
|---|---|---|
| **Налог на прибыль** | всех | базовая ставка 25% с 2025 (была 20%); для IT — льготная 5%; для отдельных компаний может устанавливаться повышенная |
| **НДС** | всех | 20%, льготные 10% и 0% |
| **Страховые взносы** | всех | общий тариф 30%; для IT — 7,6% |
| **НДПИ** | добыча (нефть, газ, уголь, руда, золото, удобрения) | привязан к цене и курсу; растёт вместе с конъюнктурой |
| **НДД** | часть нефтяных месторождений | облагает финансовый результат, а не объём |
| **Демпфер** | нефтепереработка | выплата из бюджета за поставку топлива на внутренний рынок; обнуляется при превышении порога цены |
| **Экспортные пошлины** | экспортёры | вводились и отменялись неоднократно; бывают привязаны к курсу |
| **Акциз на жидкую сталь** | металлургия | привязан к экспортной цене сляба, обнуляется ниже порога |
| **Налог на сверхприбыль** | компании с высокой прибылью | разовые сборы вводились по итогам отдельных периодов |

## 6.2. Признаки «мишени» — кого чаще облагают

Изъятия распределяются не случайно. Устойчивые признаки повышенного риска:

| Признак | Почему |
|---|---|
| **Высокая и заметная рентабельность** | публично воспринимается как «сверхдоход» |
| **Сверхдоходы от конъюнктуры** | рост прибыли не связан с усилиями компании |
| **Немобильные активы** | месторождение, труба, сеть — нельзя перенести за границу |
| **Государственное участие** | добавляется канал директивных дивидендов |
| **Экспортная валютная выручка** | легко администрируется, привязывается к курсу |
| **Монопольное положение** | база не убегает при повышении ставки |

**Практический вывод для карточки компании:** фискальный риск стоит вынести в отдельное
поле. Компания, попадающая под 3–4 признака сразу, несёт риск изъятия независимо от
качества бизнеса.

## 6.3. Эффект прецедента — то, что упускают чаще всего

Точечное изъятие бьёт не только по конкретной компании:

```
Изъятие у одной компании/сектора
      ↓
Рынок делает вывод: высокая рентабельность приглашает изъятие
      ↓
Растёт требуемая доходность по ВСЕМ компаниям с высокой маржой
      ↓
Подрезается верхняя граница оценки любой успешной истории
```

Для инвестора этот канал может быть дороже самого налога, потому что действует через
ставку дисконтирования по всему рынку, а не через прибыль одной компании.

## 6.4. Квазифискальное изъятие — налог, который не называется налогом

| Форма | Механизм | Кого касается |
|---|---|---|
| **Директивные дивиденды** | норматив выплат от прибыли для госкомпаний | госкомпании и их миноритарии |
| **Обязательные инвестпрограммы** | предписанный CAPEX | инфраструктурные госкомпании |
| **Регулируемые цены и тарифы** | продажа ниже рыночной цены | энергетика, ЖКХ, фарма (ЖНВЛП) |
| **Обязательная продажа валютной выручки** | принудительная конвертация | экспортёры (вводилась и отменялась) |
| **Льготное кредитование по предписанию** | выдача под нерыночную ставку | банки |

Эти формы не попадают в налоговую статистику, но уменьшают денежный поток так же, как налог.

## 6.5. Куда уходят госрасходы

Структуру расходов важно смотреть не в целом, а **по разделам** — от этого зависит, какой
сектор получает деньги.

| Направление расходов | Сектор-получатель | Канал доведения |
|---|---|---|
| Национальная оборона | ОПК, машиностроение, металлургия | гособоронзаказ |
| Инфраструктура | строительство, стройматериалы, металлургия | госзакупки, бюджетные инвестиции |
| Социальная политика | потребительский сектор (через доходы) | выплаты населению |
| Субсидируемая ипотека | девелопмент, банки | субсидия ставки |
| Поддержка АПК | агросектор | льготные кредиты, субсидии |
| Госзакупки лекарств | фарма | тендеры |
| Поддержка IT | IT-сектор | налоговые льготы, гранты |

**Оговорка для России:** значительная часть оборонного импульса идёт в непубличные
структуры, поэтому трансмиссия в котирующиеся акции слабая и косвенная. Не записывать
рост оборонных расходов в прямой драйвер публичной компании без проверки конкретного
канала (кто именно получает контракт).

## 6.6. Бюджетное правило и курс

```
Цена нефти ВЫШЕ цены отсечения
      → сверхдоходы направляются в резервный фонд (покупка валюты)
      → давление на ОСЛАБЛЕНИЕ рубля

Цена нефти НИЖЕ цены отсечения
      → продажа валюты из резервов для покрытия дефицита
      → ПОДДЕРЖКА рубля
```

Эти операции могут перевешивать торговый баланс в моменте. Поэтому, объясняя движение
курса, всегда проверяй направление операций по бюджетному правилу — часто именно оно, а
не цена нефти, объясняет динамику.

# ЧАСТЬ 7. ЧЕК-ЛИСТ ОШИБОК

**Общие:**

- [ ] Сказал «фактор влияет плохо» без указания, через какую метрику и на какой ступени цепочки.
- [ ] Не указал лаг — когда эффект проявится.
- [ ] Применил линейную логику там, где связь пороговая (ипотека) или разворачивается во времени (маржа банка).
- [ ] Смешал опережающие и запаздывающие индикаторы: сделал вывод о будущем по NPL или ROE.
- [ ] Взял мировую цену сырья без курса — для экспортёра значима рублёвая цена.
- [ ] Не проверил, раскрыла ли компания чувствительность сама (в примечаниях МСФО).

**Секторные:**

- [ ] Единый знак ставки для всех банков — он зависит от структуры фондирования.
- [ ] Анализ металлурга по цене стали без корзины сырья.
- [ ] Оценка золотодобытчика по cash cost вместо AISC.
- [ ] Цена угля без вычета логистики и дисконта.
- [ ] LFL без декомпозиции на трафик и чек.
- [ ] Для IT — только эффект ставки на оценку, без процикличности IT-бюджетов.
- [ ] Для девелопера — линейный пересчёт эффекта ставки без порога и без учёта эскроу.
- [ ] Для страховщика — только премии, без инвестпортфеля и его двусторонней переоценки.
- [ ] Для энергетики — «снижение ставки = плюс» без учёта компаний с денежной подушкой.
- [ ] Для агро — оценка по текущей выручке без биологических активов.
- [ ] Для фармы — крепкий рубль записан в минус (у неё он в плюс).
- [ ] Смешаны госзаказное и рыночное машиностроение.

**Фискальные:**

- [ ] Смешаны след государства (расходы) и изъятие (налоги) — у них разные знаки.
- [ ] Учтён прямой эффект изъятия, но упущен эффект прецедента на весь рынок.
- [ ] Не замечены квазифискальные формы (директивные дивиденды, регулируемые цены).
- [ ] Рост оборонных расходов записан в прямой драйвер публичной компании без проверки канала.

## Приложение. Как поддерживать методичку

**Что обновлять регулярно:**

| Что | Как часто | Почему |
|---|---|---|
| Ключевая ставка и сигнал ЦБ | каждое заседание | базовая переменная для половины секторов |
| Параметры бюджетного правила | при изменении закона | определяет курс |
| Налоговые параметры (ставки, пошлины, демпфер) | при изменениях | прямое влияние на денежный поток |
| Параметры льготных ипотечных программ | при изменениях | главный knob для девелопмента |
| Ориентировочные бенчмарки метрик | раз в год | дрейфуют вместе с рынком |

**Что не устаревает:** механизмы трансмиссии, формулы метрик, виды зависимостей, лаги,
логика разметки leading/coincident/lagging. Это ядро методички — оно писалось так, чтобы
не требовать пересмотра при каждом изменении конъюнктуры.
