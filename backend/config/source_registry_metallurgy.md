# Реестр источников — сектор МЕТАЛЛУРГИЯ

> **Назначение.** Список внешних источников, по которым платформа может автоматически
> обновлять две вкладки карточки компании: **«Рынки»** (`market.json`) и
> **«Корпоративное управление»** (`governance.json`).
> Это ПЕРВЫЙ сектор из 13 — файл задаёт формат для остальных.
>
> **Составлен:** 2026-08-07. **Компаний в секторе:** 30 тикеров.
> **Как проверялась доступность:** `curl -L` с браузерным User-Agent с dev-машины (не РФ IP),
> проверялся HTTP-код, конечный URL после редиректов, наличие целевых ссылок в HTML и
> валидность XML у RSS. Где написано «не проверял» — стоит `unknown`, URL из уже
> процитированных в `companies/*/market.json|governance.json` (то есть однажды работал).

## Легенда полей

| Поле | Значения |
|---|---|
| **вкладка** | `markets` / `governance` / `обе` |
| **частота** | день / неделя / месяц / квартал / год / событийно |
| **доступ** | `open` — свободно парсится; `antibot` — защита (нужен браузерный UA, headless или РФ-IP); `paid` — платный; `manual` — только руками; `unknown` — не проверял |
| **прио** | 1 — без него анализ неполный; 2 — заметно улучшает; 3 — приятно иметь |

### 🔴 Три системных ограничения доступа (действуют на весь реестр)

1. **Гос.сайты РФ не отдают TLS с не-РФ IP.** Проверено 2026-08-07: у `fas.gov.ru`,
   `rosstat.gov.ru`, `customs.gov.ru`, `publication.pravo.gov.ru` TCP:443 **открывается**,
   но TLS-handshake виснет до таймаута (код `000`). Это гео-блок/DPI, а не «сайт лежит».
   С боевого сервера Timeweb (РФ) они, скорее всего, **open** — но это надо подтвердить
   ИМЕННО ОТТУДА, а не с ноутбука. В таблицах помечено `antibot (гео)`.
2. **e-disclosure.ru перешёл на JS-челлендж.** Раньше хватало браузерного User-Agent
   (см. память проекта `e-disclosure-user-agent.md`). Проверено 2026-08-07:
   `company.aspx?id=30` отдаёт **200 и 372 КБ JS-заглушки** со спиннером и
   `<noscript><meta http-equiv="refresh" url="/exhkqyad">`, а не HTML компании. То есть
   старый рецепт `curl -A` **больше не работает** — нужен headless-браузер или
   переиспользование cookie после решения челленджа.
3. **RSS почти нет.** Из 30 эмитентов рабочий корпоративный RSS нашёлся у **двух**
   (GMKN, TRMK). Остальное — HTML-парсинг пресс-центров, часть сайтов SPA (RASP, ALRS).

# В. ДЫРЫ — чего не хватает и что с этим делать

### В1. Доступ

1. **e-disclosure перешёл на JS-челлендж** (проверено 2026-08-07). Это узкое место всей
   вкладки governance по малым эмитентам: для 9 тикеров из 30 это ЕДИНСТВЕННЫЙ канал.
   *Что делать:* либо headless-браузер (Playwright) один раз в сутки с сохранением cookie,
   либо переключиться на уже подключённые в `report_watch.py` зеркала раскрытия —
   `disclosure.skrin.ru`, `e-disclosure.azipi.ru`, `disclosure.1prime.ru` (им нужен ИНН, а не
   свой ID) — и завести таблицу «тикер → ИНН».
2. **Гос.сайты РФ (ФАС, Росстат, ФТС, Минпромторг, pravo.gov.ru) недоступны с dev-машины.**
   Не «сломаны» — гео-блок. *Что делать:* все проверки и сам парсинг этих источников
   запускать **с боевого Timeweb**, а на дев-машине не пытаться и не делать ложных выводов.
   Первый шаг — эндпоинт-пробник `/api/debug/probe-source?url=...`, чтобы один раз
   выяснить реальную доступность каждого из них из РФ.
3. **RSS есть только у 2 эмитентов из 30** (GMKN, TRMK) + у 4 отраслевых порталов
   (ФРТП, Prometall, Vgudok, Золотодобыча). Всё остальное — HTML-парсинг, а RASP и ALRS —
   ещё и SPA. *Что делать:* по эмитентам не строить пайплайн на RSS вообще, опираться на
   e-disclosure/СКРИН как первичный канал событий, а сайт компании — как обогащение.

### В2. Данные

4. **Титан (VSMO) и магний (MGNZ) — закрытая дыра.** Открытого числового бенчмарка нет.
   Есть только Asian Metal / Fastmarkets (`paid`) и слабый прокси FRED PPI по США.
   *Что делать:* явно ставить `data_flag` и эпистемический тег `оценка`; не притворяться,
   что у нас есть цена. Либо разово покупать доступ — но это продуктовое решение владельца.
5. **Ферросплавы, ванадий, спецстали** (CHMK, AMEZ, IGST) — то же самое: нет открытого ряда.
6. **АЛРОСА измеряется не тем индексом.** В БД лежит IDEX — это **бриллианты** (огранка),
   а АЛРОСА продаёт **алмазное сырьё**. *Что делать:* добавить Zimnisky Global Rough Diamond
   Price Index (A4.4) как основной ряд для ALRS, IDEX оставить вторым (розничный конец цепочки).
7. **SGZH не принадлежит этому сектору.** Сегежа — лесопромышленный холдинг: пиломатериалы,
   фанера, бумажные мешки. Ни один из 30 источников сектора её не описывает.
   *Что делать:* либо перенести тикер в «лесопромышленный/материалы», либо завести под неё
   отдельный мини-набор источников (бенчмарки пиломатериалов — Random Lengths/FEA, `paid`).
   Оставлять как есть — значит гарантированно писать в её «Рынки» чужие цифры.
8. **ENPG учтён наполовину.** Эн+ = алюминий + гидрогенерация. Реестр закрывает только
   металлическую половину. Для второй нужны источники энергосектора (АТС, СО ЕЭС, тарифы) —
   они появятся в реестре сектора «электроэнергетика».
9. **Доли рынка не автоматизируются.** Сейчас доли (Северсталь 33% / ММК 30% / НЛМК 23% в
   плоском прокате) берутся из статей Коммерсанта и пресс-релизов конкурентов. Ни один
   источник не отдаёт их машинно. *Что делать:* принять это — обновлять раз в квартал руками
   или LLM-извлечением из отраслевых СМИ, с тегом `оценка` и датой, а не выдавать за факт.
10. **Внешнеторговая статистика (ФТС) закрыта с 2022.** Экспортные объёмы по компаниям —
    только из их собственной отчётности и оценок отраслевых СМИ. Помечать `оценка`.
11. **Себестоимость и её драйверы не покрыты ценами.** Для угольщиков и сталеваров
    решающий фактор 2025–2026 — не цена продукции, а **ЖД-тариф** (+8,5% с 01.10.2026,
    вторая индексация за год) и налоги (акциз на жидкую сталь, НДПИ на руду).
    Их дают Vgudok (A3.1), regulation.gov.ru (A1.2) и ФАС (A1.1) — это не «новостной шум»,
    а входные параметры модели. Приоритет подключения — вровень с ценами товаров.
