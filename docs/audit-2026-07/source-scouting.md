# Разведка источников для Обозревателя — живая проверка машиночитаемости

Дата: 2026-07-27. Метод: curl с браузерным UA (Mozilla/5.0 Chrome/126), ≤3-5 запросов на источник:
статус, поиск RSS/JSON/sitemap, свежесть по pubDate, оценка ценности для дообновления карточек
(финансы / дивиденды / governance / рынки / макро / гео / институты). Всё проверено ЖИВЬЁМ — уровень
достоверности: факт на дату проверки (кроме оценок частоты — оценка по наблюдаемым pubDate).

## Сквозные выводы

1. **Отраслевые RSS в основном живы** — по 6 из 9 секторов есть рабочий фид с обновлением день-в-день.
2. **Рейтинговые агентства RSS не дают** — но у АКРА и НКР листинги server-rendered и легко парсятся
   (у НКР эмитент+дата прямо в слаге URL). Эксперт РА — JS, НРА — сломанные фиды: их отложить.
3. **e-disclosure закрылся антиботом ServicePipe** — прежний трюк «браузерный UA» больше не работает.
   Это самый ценный per-эмитент источник; развилка (headless vs платный API Интерфакса) — на владельца.
4. Trading Economics и IMF — исключить (403/ToS); World Bank подключать через официальный JSON API,
   не через новости.
5. Частоты — оценка по наблюдаемым pubDate за 1 день; при подключении закладывать polling 2–4 раза/день,
   для агентств — 1–2 раза/день с паузами (АКРА тарпитит).
